# 88 大量の接続試験と見回り（L2・表示・つながると確かめた数）

設計: docs/noah-agent-market-design.md §4.3・§8、docs/services/noah-agent-intake.md。先に 86・87。

## やること

1. L2 の接続試験。自動で呼んでよいのは、鍵が要らず、全部の道具が読み取りだけと宣言され、入力を定義から埋められる接続先だけ。見本の入力と成果を保存する。
2. それ以外の接続先は、最初に使った本人の実行の成否を L2 として数える。本文は残さない。
3. 見回り。使われている系列は毎日、L1 だけの系列は週 1 回（候補）。30 日応答が無ければ隠す。通らない物の印を外す。道具の定義が変わった系列は、つないでいる本人へ聞き直しを出す。
4. 表示。タイムラインに流すのは L2 が 7 日以内に通った系列だけ。検索と一覧には L1 の物も出し、「まだ誰も動かしていない」と書く。系列ごとに、サインインなしで読める公開のページを出す（詳細設計書 4 章）。
5. 集計。「つながると確かめた数」を口ごとに出す。台帳の行数と並べて運営の画面に出す。
6. 礼儀。名乗りと連絡先、回数制限、同じ host への間隔、寝ている Space を起こさないこと、取り下げの申し出の反映（81 と同じ窓口）。

## 変えないもの

- 読み取りだけと宣言されていない道具を自動で呼ばない。鍵の要る接続先を自動で呼ばない。
- 巡回は読むだけ。作者の版と説明を書き換えない。

## 合格条件

- 試験用の接続先で、書き込みの道具を 1 つでも持つ物は L2 の自動試験の対象から外れる。
- 接続先を止めると、次の見回りで印が外れ、タイムラインから消える。戻すと戻る。
- 同じ host への握手が 1 巡回に 1 回を越えない。
- 公開の接続先で「つながると確かめた数」が 100 を越える（最初の目標。候補）。
- tests/noah-mass-probe.test.mjs、`npm run typecheck`、`npm run lint:product`。
