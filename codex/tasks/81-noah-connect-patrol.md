# 81 作者の引き取りと並び順

設計: docs/noah-agent-market-design.md §4.3・§4.8、docs/services/noah-agent-intake.md。先に 88。並び順の変更は本人の確認の後。巡回は 88 へ移した。

## やること

1. 作者の引き取り。取り込んだ Agent を、台帳の名前空間の持ち主（GitHub のログイン、ドメイン、Hugging Face の owner）だと確かめた本人が 1 タップで引き取る。
2. 引き取った本人だけが、説明・見本・価格・取り下げを操作できる。引き取るまで無料のままにし、お金を発生させない。
3. 取り下げの窓口。作者・提供者の申し出で、掲載と巡回を止める。
4. 実測の集計。系列ごとの接続の成功率、最初の成果までの秒数、検収の合格率。
5. 並び順への反映。今のおすすめの入力に、上の実測を足す。人気と売上は入れない。

## 変えないもの

- 巡回は読むだけ。作者の版を書き換えない。
- おすすめの同意と履歴の決まり（docs/services/noah-agent-discovery.md）。

## 合格条件

- 持ち主でない本人の引き取りが拒否される。引き取り前の系列に価格を付けられない。
- 取り下げた系列が、一覧・検索・巡回から消える。
- 並び順が、同じ条件なら接続の成功率の高い系列を上に出す。実測の無い系列を加点しない。
- tests/noah-claim.test.mjs、`npm run typecheck`、`npm run lint:product`。
