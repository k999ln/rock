# 81 巡回・並び順・作者の引き取り

設計: docs/noah-agent-market-design.md §4.4・§4.6。先に 77。並び順の変更は本人の確認の後（設計書 §9 の 7）。

## やること

1. Spider の巡回。公開中の版の接続試験を、1 日 1 回やり直す。通らなくなった版は印を外し、作者へ知らせる。提供者サーバー型は疎通だけを見る。
2. 実測の集計。版ごとの接続の成功率、最初の成果までの秒数、検収の合格率。
3. 並び順への反映。今のおすすめの入力に、上の実測を足す。人気と売上は入れない。
4. 作者の引き取り。公開ソースから載った Agent を、GitHub の認可で持ち主と確かめた本人が 1 タップで引き取る。引き取るまで無料のままにし、お金を発生させない。

## 変えないもの

- 巡回は読むだけ。作者の版を書き換えない。
- おすすめの同意と履歴の決まり（docs/services/noah-agent-discovery.md）。

## 合格条件

- 接続先を止めた版の印が、次の巡回で外れる。戻すと、次の巡回で戻る。
- 並び順が、同じ条件なら接続の成功率の高い版を上に出す。実測の無い版を加点しない。
- 持ち主でない本人の引き取りが拒否される。
- tests/noah-connect-patrol.test.mjs、`npm run typecheck`、`npm run lint:product`。
