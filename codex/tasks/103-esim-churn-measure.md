# 103 続けて使う割合を測る — eSIM を入れた人と入れていない人を、同じ機能で比べる

本人の仮説（2026-11-21 22:31）: 「データでも eSIM は、アプリに比べて離脱率が低いはず」。測り方は 22:54 に決定（[07](../../docs/structure/07-decisions-from-minutes.md)、[03 の 0.3.3](../../docs/structure/03-esim.md)）。

## 決めてある事（変えない）

- 2026-11-22 に、利用者から月額は取らない形へ変わった（[07](../../docs/structure/07-decisions-from-minutes.md)）。だから、解約率の代わりに「使い続けた割合」で比べる。
- 2 つの組: `esim`（eSIM の利用権が有効な人）と `card`（eSIM なしで Noah だけを使う人。名前は既存の関数のまま）。機能は同じ。eSIM を入れた人だけの機能は作らない。
- 1 人の「始めた月」は、初めて Noah で仕事を頼んだ月。1 か月のうちに 1 回でも頼んだら、その月は「続けた」。頼まなかった月が来たら、その前の月で「やめた」とする。
- 集計は `lib/churn-cohort.ts`（実装済み・試験済み）をそのまま使う。1 人ごとに `{ arm, startedAt（始めた月の最初の利用の時刻）, periodsPaid（続けた月の数）, endedAt（やめた月の終わり。続いていれば null） }` を渡す。
  - 月ごとにやめた割合 ＝ やめた数 ÷ 結果が出た月の数。続いている人の今の月は、まだ結果が出ていないので数えない。
  - 3 か月の継続 ＝ 始めてから 3 暦月以上たった人のうち、3 か月以上続けた人の割合。
  - どちらも Wilson の 95% の幅を付ける。判定は `insufficient`・`esim_lower`・`card_lower`・`unclear` の 4 つ。
- 人数が 5 人未満の組は、数を画面に出さない（task 114 と同じ）。

## やること

1. **元の数を引く。** 仕事の記録（Work・依頼の表。`lib/noah-usage.ts` の集計と同じ所）から、1 人ごとに月ごとの利用の有無を作る。組は、eSIM の利用権の表（`lib/rockstar-entitlement-*.ts`・`lib/esim-device-entitlement*.ts`）で、その月の初めに有効だったかで決める。名前のない利用者（11-22 の会員登録の廃止の後の、ブラウザ専用の保存権限）も 1 人として数える。
2. **運営の画面。** Noah の運営の画面（task 114 の「試行」の節の隣）に、2 つの組の数・やめた割合と幅・3 か月の継続と幅・判定を出す。1 人ずつの行は出さない。

## 合格条件

- `tests/churn-cohort.test.mjs` が通る（実装済み）。
- 試験用の D1 に、2 つの組の人の仕事の行を入れると、運営の画面の数が `cohortChurn` の結果と一致する。
- 名前のない利用者も 1 人として数えられ、同じ人が 2 回数えられない。
- 5 人未満の組の数が、画面に出ない。
- `npm run typecheck`・`npm run lint:product`。

## やらないこと

- 本番 D1 への migration。広告・案内の文の変更。判定の結果で機能を自動で変えること。
