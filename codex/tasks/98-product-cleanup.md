# 98 miiの商品案内・画像と旧画面の整理

miiの設計正本に合わせて商品案内を更新し、画像の公開URLとNoahのMac接続・仕事・成果の入口を保つ。

- 製品トップ、詳細、開発状況、試作計画に4本のTowerと別体Hubを反映する。単体の限定用途、実機受入、価格・販売の状態を区別する。
- 画像コピー3点とR5図面8点を原本からAstroの開発・ビルド時に生成する。商品サイトの11 URLでバイト一致を検査する。WebOSで配信を終了した画像の原本とハッシュ検査を保全する。
- 追加機能の表示名、文書の二重索引、旧Mini CSSと旧Zemaの選択画面を整理する。Tool一覧と選択は現行Noahにある。
- Loopは固有のWebMCP操作があり、Operationsは従来の実行履歴と再実行を扱うため保留する。ブランドアイコンは既存の配信用ファイル名とハッシュ検査を維持する。
- 検証は全体の npm run verify、商品サイトの npm run test:avocado-mini-site と生成した11画像の照合で行う。
