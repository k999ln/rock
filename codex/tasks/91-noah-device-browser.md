# 91 専用の端末の中のブラウザと画面（のぞく）

設計: docs/noah-agent-market-design.md §4.2・§6、docs/services/noah-screenless.md。先に 75・84。費用が増えるので、月の上限の中で始める。

## やること

1. 面が `browser` の Agent に、専用の端末の中のブラウザ（画面なし）を渡す。本人のブラウザの profile・cookie は使わない。
2. 面が `screen` の Agent に、専用の端末の中の仮想の画面を渡す。本人の画面は渡さない。
3. のぞく。ターミナル・ブラウザ・画面を、本人が見るだけの窓で開ける。既定は閉じている。代わりに操作する機能は入れない。
4. ログインが要るサイト。雲の端末には本人のログインを入れない。相手の許可（OAuth・API）で足りない物は「準備が必要」と表示し、家の端末ができてから扱う。
5. 接続計画。面に合う置き場所だけを残す。費用の見込み（ブラウザ 4 分で約 $0.01）を接続の 1 行に出す。

## 変えないもの

- 面が `own-device` の Agent は受けない。
- 外向きの通信は接続要件の `egress` だけ。鍵を隔離環境へ入れない。

## 合格条件

- browser-use を使う試験用の Agent が、専用の端末（雲）の中で Web ページを読み、成果を返す。本人の端末では何も開かない。
- のぞく窓を閉じたままでも完了する。開いても、入力は Agent へ届かない。
- 84 の検査が通る。tests/noah-device-browser.test.mjs、`npm run typecheck`。
