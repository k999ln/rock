# 77 整える・接続試験・機械審査（Eve のビルドの実行する段）

設計: docs/noah-agent-market-design.md §4.4、docs/services/eve-agent-build.md。先に 76。隔離環境は 75、または作者の Mac runner。

## やること

1. `POST /api/noah/builds` と Work。段ごとの状態、停止、同じビルド ID の照合。
2. 整える R1〜R5。既存の `noah-project-refactor/1`（今はローカルの host だけ）を、認証付きの受け渡しで公開側から使えるようにする。変更は 1 つずつ別の差分。
3. 接続試験。何も入っていない隔離環境で接続を再現し、手数・秒数・メモリ・通信した host・見本を接続証明として版の hash に結ぶ。
4. 機械審査の 6 項目。無料かつコード公開で全部通った版は、人の審査無しで掲載する。それ以外は今の審査へ。
5. 審査の画面に、機械審査の報告と差分を出す。

## 変えないもの

- 原本は変えない。固定テストが失敗した変更は採らない。si の出力だけで合格にしない。
- 外部の有料モデルへ自動で切り替えない。

## 合格条件

- OpenAI 互換の SDK を直接呼ぶ例が、作者の API キー無しで、中継のモデルで固定テストを通る。
- 宣言に無い host へ通信する例は、接続証明が通らず、印が付かない。
- 壊れる変更の例が拒否され、原本の download が入力 bytes と一致する。
- 別の本人が、掲載された版を task 74 の 1 クリックでつなげる。
- tests/noah-build-*.test.mjs、`npm run typecheck`、`npm run lint:product`。
