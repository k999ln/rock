# 93 入れ替える（更新・戻す・切る・移す）

設計: docs/noah-design.md §4.2、docs/services/noah-agent-operations.md、docs/services/noah-device-store.md。先に 74。

## やること

1. つないだ Agent と、端末に入れたモデルを 1 つの一覧に出す。正本は account。
2. 更新。新しい版が出た時、権限・道具の定義・料金・通信先に差が無ければ自動。差がある時だけ 1 タップで聞き直す。固定（pin）した版は自動で上げない。
3. 戻す。前の版へ 1 タップ。
4. 切る。新しい実行を止め、端末の cache を消す。成果と費用の記録は残す。
5. モデル。裏で取得し、複数の Agent で共有し、使用中は消さない（既存）。容量が足りない時は、使っていない物を挙げて本人に選ばせる。
6. 移す。端末を足した時・替えた時、置き場所の変更をまとめて 1 回の確認で行う。

## 変えないもの

- 版の固定と hash の照合（`lib/noah-instances.ts`）。返金・撤回・審査失効の後の新規実行 0。
- 置き場所を黙って変えない。

## 合格条件

- 権限が増える更新は、本人の確認無しでは適用されない。差の無い更新は自動で入り、前の版へ戻せる。
- 切った後、端末に配布物が残らず、成果と費用の記録は残る。
- 2 台目の端末を承認すると、つないだ Agent の一覧がそのまま出て、1 回の確認で置き場所を移せる。
- tests/noah-library-lifecycle.test.mjs、`npm run typecheck`、`npm run lint:product`。
