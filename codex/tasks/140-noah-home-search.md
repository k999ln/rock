# 140 — Noahの重複入口を統合

本人指示（2026-11-26）: Agentを探すとホームは同じ役割なので統合。`/noah#timeline` も同じホームへまとめる。

- `/noah` でAgent検索・カテゴリ・提供元の絞り込みを行う。検索中は結果を先に表示し、解除後は選択カテゴリを保持してホームへ戻る。
- `/noah/explore` と旧aliasは検索語・提供元・カテゴリ・trial札・fragmentを保持してホームへ転送。旧Toolタブも同じホームで表示する。
- 公開メニューはホーム1件だけを置き、Agentを探す／タイムラインの重複入口を外す。タイムラインはホーム内の節とし、古いhashでもホームの一覧を別画面へ置き換えない。
- 登録情報・任せる範囲のメニューを人型アイコンへ統合。ココナラ専用メニューを外し、旧入口はホームへ転送。個別Agentのページは維持。
- API、仕事、登録、保存、権限、課金は維持。別チャットの未コミット変更は隔離作業先で保全。

合格条件: 条件付き旧URLに転送循環がない。ホームが条件どおりdiscover APIを読む。メニューはホーム1件。390px/1280pxで検索とタイムラインの導線を確認。`npm run verify` とPRの全CIが成功。公開前に最新mainとSites保存ソースのtree一致を照合する。

対象試験・typecheck/lint/build・本番構成のHTTP計測は成功。最新の全体検証・390px/1280px表示・main/SitesのSHAとtree・公開版の記録は [PR #84](https://github.com/iceiceice999/rock/pull/84) に残す。
