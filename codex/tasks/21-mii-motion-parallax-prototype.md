# 21 mii Gen1 試作 — 1 プロジェクター＋1 壁＋頭追跡

目的: 「眼鏡なしで、壁の中に奥行きのある 3D が見える」を最小構成で成立させる。一人用。

## やること
1. `systems/rock-star-os/experiments/motion-parallax/`: 
   - 入力: 1 台の RGB/depth カメラ（手持ちの Webcam でも可）→ 顔検出 → 両眼位置（3D）。
   - 描画: Three.js か Unity の off-axis projection（視点に合わせて視錐台をずらす）。壁の物理サイズ・位置・プロジェクターの投影領域を設定ファイルで持つ。
   - 出力: プロジェクター（手持ちのもので可）に全画面。
   - 遅延計測: カメラ→描画の end-to-end ms をオーバーレイ表示。
2. 最初のコンテンツ 3 つ: ①壁の向こうに部屋が続いている（箱の奥行き）②床に正四面体が置いてあり、歩くと向きが変わる ③壁に相手の等身大シルエット（遠隔プレイの前触れ）。
3. `docs/mii/gen1-prototype-report.md`: 遅延、破綻する動き（速い首振り）、照度条件、必要 fps。写真 2 枚。
4. この試作を Eve から起動できるように `lib/mii-*.ts` に「spatial scene を開く」Job 型を 1 つ足す（Game runtime の既存枠を使う）。

## 合格条件
- 1 人がカメラの前で左右に 1m 動いたとき、壁の像が破綻せず奥行きが見える（動画を CHANGELOG からリンク）。
- end-to-end 遅延 < 50ms を目標、実測値を report に。

## やらないこと
- 複数人対応。AIRR。専用ハードの購入提案（手持ちで）。

## 入力

設計書 docs/mii/design/ の 05（描画手順）、08 §4（投影校正）、13（4 週間計画の Week 3）。受入は 11 章 D-1〜D-5。
