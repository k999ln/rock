# 121 Noah の集める場所を増やし、新しく使いやすい物を上へ

本人指示（2026-11-22 05:26）「Noahでエージェント常に集めるシステム作って欲しい、twitterとかredditとか、github repoとか他に考えられる場所探して、常に新しく使いやすいものが上に上がるように。今の問題はtwitterでしかマーケットプレイスのようなものがないこと。新しいrepoを探す場所が他にない」と、その後の回答。task 120（クラウドの継続収集）の上に足す。[サービス契約](../../docs/services/noah-agent-collection.md) の「出所を増やす（task 121）」節。

## 本人の回答（2026-11-22）

- X・Reddit を読む系は Codex にやらせる。Glama・Smithery・PulseMCP は「無料？勝手に嗅ぎ取ってきといて」。
- 見つけたがスマホから動かせない物は、別の「新着」の列に出す（グリッドは今動かせる物だけのまま）。
- 使いやすさは、人が使った実績・握手で分かる事・話題の度合いの全部で測る。
- 「常に」はどこで動かすか → 「携帯の計算資源を使ったコードや独自 LLM を作ったのでは？」への答え: Sky Compute Grid は設計と試験だけ（携帯のアプリは未作成）で、規則上、公開の文章の埋め込みしか動かさず、ネットを読む仕事はできない。独自 LLM は計画だけ。並びは ML なしと決めてあるので LLM は要らない。集める仕事は task 120 の GitHub の定期実行（5 分ごと）で動いている。

## 範囲

- 出所を足す（鍵なしの公開 API・許諾を確かめた一覧だけ）: Hacker News（Algolia）、GitHub の MCP の新着（topic・直近 14 日）、Hugging Face の MCP Space（タグ mcp-server）、npm（MCP の鍵語）、Docker の MCP 一覧（mcp 名前空間）、awesome 一覧（MIT の 3 つ）。Smithery は無料の鍵 `SMITHERY_API_KEY` が有る時だけ。
- 読まない所: Glama（鍵と、全画面への表示義務）、PulseMCP（新 API は申請制）、Bluesky の未認証の検索（403）。X・Reddit・Bluesky は、運営の Codex が読んだリンクを `scripts/noah-collector-social.mjs` で受け取る（投稿の本文・利用者名は受け取らない）。
- 並び: `lib/noah-collection.ts` の `noahCollectionHot`。Reddit の hot の形（log10(票) + 出た時 / 12.5 時間）。票 = 話題（スター・いいね・点・取得数などを重み付き、1 つの数は 1,000 票まで）＋ 動かし方（スマホで今すぐ 40・ブラウザ 15・Mac 5・鍵 0）＋ 日本語の説明 10 ＋ 別の出所での話題 10。学習も乱数も使わない。紹介の欄に「新しく使いやすい順 / 出た順」。
- カードに動かし方（スマホで今すぐ・ブラウザで試せる・Macで動く・鍵が要る）。スマホで今すぐの物は「Noahで開く」で詳細へ。
- 握手の済んだ系列を、一覧（グリッド）へ自動で入れる（`--import`）。収集機の鍵の HMAC（path 付き）で `POST /api/noah/intake/import`。変わった系列だけ、1 日 400・1 回 120 まで。載らなくなった系列は今の行を送って本番でも外す。成人向けの語に当たる物は入れない・出さない。
- グリッドのお試し（まだ実績の無い物）の並びを、新しく握手が通った順に。押すだけで試せる物は 3 日分新しく扱う。
- 本番 D1 migration なし。

## 合格条件

- 出所ごとに期限・失敗の待ち（Retry-After を守る）・ETag が残り、1 つの出所の失敗で他が止まらない。
- awesome 一覧と npm の初回に読んだ物は新着にしない（30 日前）。後から増えた物だけが新着。
- 投稿の本文・利用者名・追跡の ?ref を保存も掲載もしない。成人向けの語に当たる紹介は出さない。
- 収集機からの取り込みは、掲載用の署名（別 path）・壊れた署名・Origin 付きを拒む。同じ物を二度送らない。日の上限を守る。
- 鍵の無い収集機が、Codex の X の紹介を空で上書きしない。
- 試験 `tests/noah-collection-sources.test.mjs`（10 本）と、既存の収集・取り込み・ピンの試験。

## 引継ぎ

- 本番の配備（Sites 公開版の更新）は Codex。配備までは、収集機の取り込みは `not_ready`（失敗にしない）、新しい出所の掲載は 400 で、その回の Actions が失敗表示になる。
- 任意: Smithery の無料の鍵を Actions secret `SMITHERY_API_KEY` へ（ノエルのアカウント。鍵はチャット・Git に書かない）。
- Codex の X・Reddit・Bluesky の読み取り: 検索で見つかる公開ページを人の速さで読み、`leads.json` を書いて `scripts/noah-collector-social.mjs --publish https://avoado.si` で掲載。ログインしたままの自動読み取りは X・Reddit の規約で禁止されているので、しない。
