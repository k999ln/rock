# 82 提供者サーバー型（利用権の受け渡し・A2A・許可の再利用）

設計: docs/noah-agent-market-design.md §4.3・§4.9・§5、docs/sky-commerce-design.md §11、docs/sky-mcp-architecture.md。先に 74・86。相手の許可（OAuth）の登録と MCP の新しい版は 86 へ移した。

## やること

1. 利用権の受け渡し。Noah が出す短命の利用権を、提供者が自分のサーバーで確かめる。`sky-paid-access/1` の設計を実装し、Sky Tool SDK に受け口を足す。提供者サイトの会員登録を要らなくする。
2. A2A の口。カードを読み、0.3 系と 1.0 の両方で話す（実測では 0.3 系が大半）。署名付きカードの検証（JWS、正規化）を足す。署名は内容の一致の証拠で、作者の身元の保証にしない。
3. 外部サービスの許可の再利用。最初の 1 回だけ本人が許可し、次の Agent からは接続の画面の同意に含める。

## 変えないもの

- token を別の接続先へそのまま渡さない。鍵を入力欄へ貼らせない。
- 提供者が利用権を確かめられない有料 Agent は売らない。

## 合格条件

- 利用権の無い本人、返金済みの本人の呼び出しを、提供者側の受け口が拒否する。
- 0.3 系のカードの接続先と、1.0 の接続先の両方へ、同じ画面からつながる。
- 2 つ目の Agent が、同じ外部サービスを再入力無しで使える。
- tests/noah-provider-place.test.mjs、`npm run sky:check`、`npm run typecheck`。
