# 90 手元だけの一周（PC の前に座らない受入）

設計: docs/noah-design.md §1・§3.4、docs/noah-agent-market-design.md §1.3・§4.5、docs/services/noah-one-click-connect.md、docs/services/noah-screenless.md。先に 74・87。動く所は、提供者のサーバーか、裏で動いている本人の Mac。

## やること

1. スマホの幅で、登録（パスキー）→ カード →「接続」→ 1 文で頼む → 画面を閉じる → 通知 → 成果を受け取る → 切る、を通す。途中に PC の前に座る手順を残さない（Mac は、承認済みで裏で動いている前提）。
2. 完了と許可待ちの通知。対応する端末は通知、それ以外は次に開いた時の一覧。前面に割り込まない。
3. 「あなたの番」の一覧。許可・ログイン・人の判断が要る仕事を集める。
4. 端末の一覧。家・手元・雲を同じ並びで出す。つないだ Agent の置き場所を見られる。
5. 受入の自動試験。専用の端末の中のブラウザ（画面なし）と受入用のアカウントで、上の一周を回す。本人の Mac の画面で操作しない。

## 変えないもの

- 本人確認、同一 Origin、ownerScope。Broker の実行前確認。
- 受入用のアカウントは支払いと外部送信を持たない。本番で使うかは本人が決める。

## 合格条件

- 幅 390 の実ブラウザで、提供者の Agent と、本人の Mac で動く Agent の両方について、PC の前に座らずに一周が終わる。接続の手数は 1 タップ以下、入力は依頼の 1 文だけ。
- 依頼の後にブラウザを閉じ、通知から開き直して成果がある。
- 一周の間、操作を塞ぐ進行表示が出ない。同時に 2 件頼める。
- tests/noah-phone-loop.test.mjs（画面なしのブラウザ）、`npm run typecheck`、`npm run lint:product`。
