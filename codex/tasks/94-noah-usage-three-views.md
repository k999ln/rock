# 94 利用の記録を 1 か所に（利用者・提供者・運営）

設計: docs/noah-design.md §3.8・§4.5、docs/services/noah-agent-usage.md。先に 74・87。

## やること

1. 記録する所を 2 つに限る。受け渡しの完了（`/api/noah/runner` の finish）と、道具を持つ担当の完了。そこで 1 回だけ、誰が・どの系列のどの版を・どこで・結果・秒数・トークン・費用・価格を記録する。依頼と成果の本文は入れない。
2. 利用者の画面。自分の利用、費用、無料枠の残り、月の上限。上限で新しい実行が止まる（Wallet の予約）。
3. 提供者・作者の画面。自分の Agent の接続数、成功率、最初の成果までの秒数、売上。個人は出さない。人数が少ない区分は出さない（候補: 5 人未満）。
4. 運営の画面。つながると確かめた数、失敗、費用、無料枠の消費、濫用の兆候。
5. 今の集計 API（`lib/noah-usage.ts`）と外部利用報告の SDK は残し、同じ記録を読む。

## 変えないもの

- 本人・提供者・運営の越権取得 0。異なる通貨の合算 0。未計測を無料と表示しない（既存の合格条件）。

## 合格条件

- 同じ完了の再送で、記録が 2 回にならない。
- 提供者が、利用者個人を特定できる値を取得できない。
- 月の上限に達した本人の新しい実行が止まり、理由が表示される。
- tests/noah-usage-views.test.mjs、`npm run typecheck`、`npm run lint:product`。
