# デザイン参照ライブラリ（Noah）

Noah の画面を作る時に見る、参照の画像と、そこから取り入れる事の記録。本人の指示（2026-11-22 01:48）「実際に使えるように参照ライブラリの雛形を作って。ムードボードとコンポーネント用のフォルダ、記入例つきのREADME、AGENTS.mdに追記する文も入れて」で Codex が作った雛形を、Noah の実際の参照で埋めて rock に入れた。

## 使い方

1. 画面を作る前に、このファイルと、対象の画面に関係する画像を見る。
2. 配色・書体・写真・余白など、画面全体の方向は `moodboard/`。カード・タブ・一覧など、1 つの部品の置き方や動きは `components/`。
3. 画像を足したら、下の「追記用の型」で、取り入れる事・使う所・確かめる点・出典を書く。動きも参考にしたい時は、操作の前後の画面と元のページを添える。
4. 作った後は、対象の画面をスマホ（390 px）と PC（1280 px）の幅で開き、「確かめる点」と見比べて直す。
5. 画像は WebP にして、1 枚 300 KB 以内にする（リポジトリを重くしない）。

- **画像** `moodboard/noah-yohaku-photo-grid.webp`

## 追記用の型

```markdown
### ［参照の名前］

- **画像** `moodboard/［ファイル名］.webp` または `components/［ファイル名］.webp`
- **取り入れる事** ［色・書体・余白・置き方・動きの、具体的な特徴］
- **使う所** ［対象の画面・部品］
- **確かめる点** ［できた画面で見比べる点。スマホと PC の両方］
- **出典** ［URL と作者、または本人の指示と日時］
```
