# デザイン参照ライブラリ（Noah）

Noah の画面を作る時に見る、参照の画像と、そこから取り入れる事の記録。本人の指示（2026-11-22 01:48）「実際に使えるように参照ライブラリの雛形を作って。ムードボードとコンポーネント用のフォルダ、記入例つきのREADME、AGENTS.mdに追記する文も入れて」で Codex が作った雛形を、Noah の実際の参照で埋めて rock に入れた。

## 使い方

1. 画面を作る前に、このファイルと、対象の画面に関係する画像を見る。
2. 配色・書体・写真・余白など、画面全体の方向は `moodboard/`。カード・タブ・一覧など、1 つの部品の置き方や動きは `components/`。
3. 画像を足したら、下の「追記用の型」で、取り入れる事・使う所・確かめる点・出典を書く。動きも参考にしたい時は、操作の前後の画面と元のページを添える。
4. 作った後は、対象の画面をスマホ（390 px）と PC（1280 px）の幅で開き、「確かめる点」と見比べて直す。
5. 画像は WebP にして、1 枚 300 KB 以内にする（リポジトリを重くしない）。

## ムードボード

### 図解のカード（紙の手触り）

- **画像** `moodboard/noah-diagram-cards.webp`
- **取り入れる事** 分野ごとの淡い色の面（緑・橙・青）と、紙の粒子。上に大きな日本語の動詞句（「名前をアラビア書道に」「単語を復習カードに」「写真を動かす」）。中央に「入れる物 → できる物」の絵。下に、細い明朝の英字で Agent の名前。1 枚に言う事は 1 つ。
- **使う所** Noah のホームのピン（今は頭文字の面）・Agent の詳細の上・SNS に出す画像。
- **確かめる点** スマホ 2 列でも、見出しが 2 行以内で読める。色の面は分野で決まり、同じ分野は同じ色。絵が説明の代わりになっていて、説明文を読まなくても何ができるか分かる。
- **出典** Codex の「図解風の画像生成方法を探す」（2026-11-22 05:52 に生成）。本人の指示「ピンタレストみたいな画像の中身ってさ図解みたいな感じのやつ」「デザイン性いいやつ」「Paper Shaders で、さっきの図解カード 3 枚を Noah のホームに入れた感じ見せて。スマホ 2 列で見たい」。

### 余白の写真の並び

- **画像** `moodboard/noah-yohaku-photo-grid.webp`
- **取り入れる事** 静かな色（生成り・土・深い緑・墨）の写真を、余白を取って並べる。1 枚ずつが主役で、文字は最小。光は柔らかく、彩度は低め。
- **使う所** ボードの表紙・ホームの雰囲気・保存の画面。
- **確かめる点** 色の強い要素（ボタン・印）は 1 画面に 1 色まで。写真の間の余白が、カードの角の丸みと揃っている。
- **出典** Codex の試作「余白」（2026-11-22 00:27 に生成）。本人の指示「見かけはピンタレストにしたいけどね」「ピンタレストみたいに画像で探せて、X みたいにおすすめが変わる画面」。

## コンポーネント

### ピンのグリッド（今の本番）

- **画像** `components/noah-pin-grid-v169.webp`
- **取り入れる事（守る事）** 高さ 3 段のカードを、いちばん短い列から置く（Masonry）。カードの下に、名前・説明 2 行・提供元の host・「押すだけで試せる」などの印。分野の札（いろいろ・お金・税・学び・暮らし など）。
- **使う所** `/noah` のホームと、ボードの頁（`components/noah-pin-grid.tsx`）。
- **確かめる点** 幅 375 px で 2 列、最大 6 列。並べ直してもカードの形が変わらない。仕様は `docs/noah/spec-115-pin-grid.md`。
- **出典** 本番の第 169 版（2026-11-22 04:17 の画面）。

### タイムラインとトーク（よりみち）

- **画像** `components/yorimichi-timeline-talk.webp`
- **取り入れる事** 画面の下の 2 つのタブで「タイムライン」と「トーク」を切り替える。トークのタブに未読の数。タイムラインは「すべて／フォロー中」。投稿は、丸い頭文字・名前・@ID・何分前、本文、写真、返信といいねの数。右上に「投稿する」の主ボタン。タブを戻すと、読んでいた位置に戻る。
- **使う所** Noah のタイムラインと、Agent とのやり取りの一覧。
- **確かめる点** 幅 320 px と 390 px で横にはみ出さない。タブを行き来しても、読んでいた位置に戻る（試作で確かめた事）。
- **出典** Codex の試作「よりみち」（2026-11-21 23:37。Phanpy と Chatscope を参考）。本人の指示「twitter feed repo みたいなのない？タイムラインの見え方真似したい、あとは Line の UI も直感的に操作できるようにしたい」。

## 追記用の型

```markdown
### ［参照の名前］

- **画像** `moodboard/［ファイル名］.webp` または `components/［ファイル名］.webp`
- **取り入れる事** ［色・書体・余白・置き方・動きの、具体的な特徴］
- **使う所** ［対象の画面・部品］
- **確かめる点** ［できた画面で見比べる点。スマホと PC の両方］
- **出典** ［URL と作者、または本人の指示と日時］
```
