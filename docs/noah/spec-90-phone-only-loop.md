# 仕様書 90 — 手元だけの一周（PC の前に座らない受入）

task: [codex/tasks/90-noah-phone-only-loop.md](../../codex/tasks/90-noah-phone-only-loop.md)。先に要る物: 87 のローンチ分（L6）まで。
[ローンチの最小限](mvp-launch.md) の L9。**この仕様は、全部がローンチの範囲。** 新しい機能は作らない。「出してよいか」を、試験と実機の表で判定できるようにする。

## 1. 完成の姿

- 「スマホだけで、PC の前に座らずに、選ぶ・接続・頼む・受け取る・切る が終わる」を、1 本の自動試験と、実機の確かめの表で言える。
- 本人の指示の 4 つを、判定できる形にする: ① 座らずに一周できる。② 閉じても進む。③ 画面を取らない。④ 見張らせない。
- 試験は、本人の Mac の画面を操作しない。実機の確かめは、スマホのブラウザで人が行う。

## 2. この仕様で決めた事

| 決めた事 | 理由 |
| --- | --- |
| 自動試験は、今ある 2 つのやり方で書く: API は `node:sqlite` の一時 DB と、試験の中の相手（`tests/helpers/noah-launch-fixture.mjs` と同じ持ち方）。画面は、部品を訳して木を調べる（`tests/noah-timeline-ui.test.mjs` と同じ） | このリポジトリに、実ブラウザを動かす試験の道具は入っていない。足さない |
| 幅 390 での見え方は、自動試験で言えない。実機の表（5 章）で確かめ、結果を PR 本文に書く | 部品の木からは、折り返しやはみ出しが分からない |
| ローンチの一周に、通知と「あなたの番」を入れない | 入力欄で頼む仕事は、長くても 28 秒で終わる。次に開いた時の一覧で足りる。「あなたの番」に出る物（相手の許可、モデルが選んだ書き込みの道具）は、ローンチの範囲に無い |
| 家の端末（Mac）の道は、この受入に入れない | 今の `/noah/launch` の受入は task 71。ローンチの条件にしない（[ローンチの最小限](mvp-launch.md) の D12） |

## 3. 一周の自動試験（`tests/noah-phone-loop.test.mjs`）

相手は、試験の中の関数（握手・一覧・呼び出しに応える合成の接続先。検証キットの [noah-mouth.test.mjs](../design-validation/noah/noah-mouth.test.mjs) の `server()` を `tests/helpers/` へ移して使う）。道具は 3 つ: 読み取りだけで入力なし（`stats`）、読み取りだけで入力 1 つ（`lookup`）、読み取りだけの宣言なし（`send_note`）。

試験が呼ぶのは、画面が呼ぶのと同じ入口だけ。DB を直に書かない（最初の取り込みを除く）。土台は、検証キットの [noah-loop.test.mjs](../design-validation/noah/noah-loop.test.mjs)（参照実装だけをつないだ一周。通信も保存もしない）。ここでは、同じ一周を、本物の入口と一時 DB を通して行う。

| # | 段 | 呼ぶ物 | 確かめる事 |
| --- | --- | --- | --- |
| 1 | 取り込む | 合図（`/api/noah/intake/tick`）を、署名つきで 2 回 | 1 回目で候補が入り、2 回目で握手が通って、系列が「まだ誰も動かしていない」に出る |
| 2 | 見つける | `GET /api/noah/intake`（未サインイン） | その系列が 1 件。印は `unverified`。`oneTap` が真 |
| 3 | 計画 | `GET /api/noah/connect-plan?agent=`（未サインイン → サインイン済み） | 未サインインは「サインイン」が 1 タップ。サインイン済みはタップ 0 |
| 4 | つなぐ | `POST /api/noah/connect` | 1 回で `connected`。相手への要求は握手だけ（`tools/call` が 0 回） |
| 5 | 道具 | `GET /api/noah/connect/[id]/tools` | 3 つ。`stats` は `required: 0`、`send_note` は `needsConfirm` |
| 6 | 頼む（押すだけ） | `POST /api/noah/ask`（`stats`） | 202。**この後、読み直しを 1 回も呼ばずに**、Work に成果が入る（閉じても進む） |
| 7 | 頼む（入力あり） | `lookup` に文字 1 つ | 成果に、送った値が返っている。相手が受けた本文に、本人の ID が無い |
| 8 | 頼む（確かめ） | `send_note` を `confirm` なし → あり | なしは `failed` で、相手への `tools/call` が増えない。ありは `succeeded` |
| 9 | 同時 | 6 と 7 を、待たずに続けて送る | 2 件とも `succeeded`（1 件が、もう 1 件を待たせない） |
| 10 | 動いた | `GET /api/noah/intake` | 同じ系列が「動いた」の先頭。印は `one_click` |
| 11 | 受け取る | `GET /api/noah/ask/[id]` | `result.text` が、Work に入った成果と同じ。Work は `review` で、通った step が無い（相手が返した内容を、確かめた事にしない） |
| 12 | 切る | `POST /api/noah/connect/[id]`（`disconnect`） | 「つながっているもの」が空。Work の行数は変わらない。新しい依頼は 409 |
| 13 | 端末の表 | 一周の前と後で、`noah_runner_devices`・`noah_runner_commands`・`noah_instances` の行数 | 変わらない（本人の端末を使っていない） |
| 14 | 手数 | 4 の計画の `cost` と、6〜8 の入力 | 接続のタップ 0・入力 0。頼む時の入力は、道具の項目だけ |
| 15 | 送った数 | 一周の後の、その接続先の `noah_probe_hosts` の行と、相手が受けた要求の記録（試験の時計は止めておく） | `user_count` が、利用者の操作から始めた握手の数（接続 1・道具の一覧 1・依頼 6）と同じ 8。相手が受けた `initialize` は、巡回の 1 回を足した 9。`tools/call` は、成果が返った依頼の数と同じ 5（確かめ無しの 1 件は、呼んでいない） |

同じ試験の中で、切り替えを閉じた時（`NOAH_INTAKE_PUBLIC`・`NOAH_ASK_FORM`）に、2 が 404、4 と 6 が 503 になる事も確かめる。上限（つなぐ前・頼む前・接続先の枠）に当たった時の動きは、74 の 11.6 と 87 の 11.6 の試験で確かめる。この一周は、既定の上限に当たらない。

## 4. 画面の決まりの試験（`tests/noah-ready-ui.test.mjs`）

部品を訳して、木と文を調べる。対象は `noah-ready.tsx`・`noah-ready-detail.tsx`・`noah-card.tsx`・`noah-connect-button.tsx`・`noah-ask.tsx`・`noah-work-list.tsx`。

| 決まり | 調べ方 |
| --- | --- |
| 1 枚のカードに、主ボタンは 1 つ | `button` と、ボタンの見た目の `a` の数 |
| 印・動く所・料金が、文字で出る（色だけで分けない） | 文に「1 クリック」か「まだ誰も動かしていない」、「相手のサーバー（<host>）」、「無料」 |
| 送り先が、接続の前と、頼む欄に出る | 「入力は <host> へ送られます。」 |
| 出どころが出る | 「出どころ: Official MCP Registry」。「提携」「公認」「公式パートナー」の語が無い |
| 進行で画面を塞がない | `dialog`・`aria-modal`・全画面を覆う class を持つ要素が無い。進行は、ボタンの文と、一覧の行だけ |
| 提供者の文を、HTML として出さない | `dangerouslySetInnerHTML` を使っていない。説明に `<script>` を入れた項目で、木に `script` の要素ができない |
| 画面に出さない言葉 | MCP・OAuth・token・runner・lease・container・hash・JSON が、見出しとボタンと説明の文に無い（提供者の文と、成果の中身は除く） |
| 確かめ | `needsConfirm` の道具で、最初の「頼む」が `POST` を呼ばない |
| 読み直し | 終わっていない依頼が無い時、定期の読み直しを置かない。`document.hidden` の間は読まない |

## 5. 実機の確かめ（本番。審査者の account。結果を PR 本文と、出す前の記録に書く）

スマホ（幅 390 前後）のブラウザだけで行う。PC を開かない。切り替えは閉じたまま（審査者には見える）。

| # | やる事 | 合格 |
| --- | --- | --- |
| 1 | `/noah/ready` を開く | 横に動かない。カードの文が切れて読めない所が無い。押す所が指で押せる（44px 以上） |
| 2 | 「押すだけで試せる」で絞り、1 つ開いて「接続」 | 1 回押して「頼む」になる。5 秒以内。別の画面へ飛ばない |
| 3 | 押すだけの道具を選んで「頼む」 | 成果が出る。「<host> が返した内容です。」が付く |
| 4 | 入力の要る道具で頼む | 欄の説明が読める。必須の欄が先。誤りは欄の下に出る |
| 5 | 読み取りだけの宣言が無い道具で頼む | 最初の 1 回だけ、確かめが出る。「やめる」で何も送られない |
| 6 | 頼んだ直後に、ブラウザを閉じる。1 分後に開く | 成果が、仕事の一覧にある |
| 7 | 頼んだ直後に、別の Agent の画面へ移る | 移れる。前の仕事は進んでいる |
| 8 | サインインしていない状態で「接続」 | パスキーの後、同じ画面に戻り、押し直さずにつながる |
| 9 | 相手が止まっている物（運営の画面で、握手が通らない物を選ぶ）を、審査者として開いて「接続」 | 「相手のサーバーが応答しません。時間をおいて試してください。」。画面は固まらない |
| 10 | 「切る」 | 「つながっているもの」から消える。成果は、仕事の一覧に残る |
| 11 | 3 種の Agent（押すだけ／入力あり／確かめが要る）で 2〜10 | 3 つとも通る |
| 12 | 一周の間 | スマホの他のアプリ・通知・クリップボードに、Noah が触れた形跡が無い。Mac を起こしていない |
| 13 | **開けた直後に**（切り替えを開けて最初に）: account を持っていない人が、別のスマホで `/noah/ready` を開き、「接続」から登録（パスキー）して戻る | 押し直さずにつながり、押すだけの道具で成果が出る。審査者でない account で通る |

1〜12 が 1 つでも通らなければ、出さない。通らなかった行と、その時の画面の文を書く。13 が通らなければ、すぐに切り替えを閉じる（[97](spec-97-launch-ops.md) の 7 章）。
