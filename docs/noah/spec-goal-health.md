## 2. 何をするか

- 目的: 4 週間（28 日分）、毎朝の体調を記録して、週ごとに振り返る。28 日分そろったら「完成」（続けてもよい）。
- 毎朝: 3 つを 5 段で選ぶ（よく眠れたか・体の調子・気分）。メモは 140 字まで、無くてもよい。同じ日は書き直せる。
- 振り返り: その週（月曜から日曜）の記録の日数、3 つの平均（小数 1 桁）、先週より高い・低い・同じ、3 つの合計がいちばん高い日と低い日、メモ。**助言・病気の判断・薬の指示は出さない**（数と並びだけ）。
- 画面に必ず出す文: 記録と振り返りの道具で、病気の判断や薬の指示はしない。気になる症状は医師・薬剤師へ。急に強い症状は医療機関へ。記録はこの端末のブラウザにだけ保存し、Noah へ送らない。
- 値段: 無料（差し引きも月額も無い）。

## 3. 記録の置き場所（体の情報なので、外へ出さない）

- この端末のブラウザの保存先（localStorage、`noah-goal-health/v1`）だけ。Noah のサーバー・D1・R2・ほかの会社へは送らない。言語モデルも使わない。
- 本人は、記録を JSON で書き出せる。全部消せる（2 回押す。ブラウザの確認の窓は使わない）。
- ブラウザの保存が止まっている時は、保存できない事を画面に出す（黙って捨てない）。
- 別の端末・アカウントとの同期は無い（同期するなら、置き場所と同意の文を先に決める。本人の判断）。
