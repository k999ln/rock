# 786系列の接続と稼働表示

2026-11-23。本人指示により、研究台帳を既存のNoah実行経路へ結び付け、本番で成果を受け取った系列を確認時刻付きで表示する。

- 786系列の正規URLを既存project identityへ照合。既存の接続・保存・評価は維持し、調査の別名を実行先にしない。
- 提供元のAPI定義を再取得して接続確認を記録。成果受領の成功だけを本番利用の証拠とする。研究JSONやローカル試験結果は本番成功へ昇格しない。
- 公開状態にはproject ID・接続方式・定義hash・確認/成功時刻だけを保存。利用者ID・依頼・成果・認証情報を入れない。
- 定義変更、失敗、24時間の確認期限切れで利用可能の表示を戻す。既存の巡回と利用時確認を使い、Agentを自動実行して健康確認しない。
- 一覧は10秒ごと・画面復帰時に更新。画面を閉じた間は停止し、取得失敗時は古い値であることを示す。
- 提供元へ実行済みの仕事の停止は、Noahの受領停止と提供元への停止要求を区別する。対応のない提供元の計算停止を保証しない。

受入: 重複なし786系列、定義変更/失敗/期限切れの状態遷移、同一依頼の再送防止、本人だけの成果保存、実在Agentの本番成果受領・再表示・停止、既存UIの保持。正本mainとSitesソースtree一致を確認して配備する。

接続調査: `data/noah-agent-connection-assessment.json` に786系列の条件を記録。Hugging Face 155系列の公開状態/API定義、他631系列の資料を確認し、631のうち16件は個別の公式資料確認、615件は自動一次選別である。分類は稼働の証拠へ昇格しない。

稼働判定: 実仕事の入口と確認したendpointだけが成功状態へ昇格する。helperのreturnedは数えない。HFの公開ソースrevisionとAPI定義を指紋に含め、以前の版の成果を新しい版の成功に使わない。成功時刻・接続確認時刻の両方に24時間の期限を設ける。10秒表示更新は表示中だけ実行し、裏側の公開メタデータ再確認は毎時・一度に2件まで。成功を保つための自動推論は行わない。
