# Mini200 E1 機構・音響区画案

2026-09-21。ゲーム計算機を本体1台へ内蔵する新構成の配置検討。D0の198W x178D x198Hと前面3丸窓を**外観仮参照**とし、ユーザーの外観承認や製造完成とは扱わない。D0の4本体/旧GS+Theia光学計算を、そのまま本案の機能や性能へ流用しない。実機試験0件。

## 外形と収納の意味

足4mmを含む公称198 x178 x198mm、全体±1mmの設計予算から最大199 x179 x199mm。幅・奥行を含む全軸200以内は追加提案。壁厚2±0.2も仮予算であり材質/加工公差は未確定。外部AC電源、取付支持、差込プラグとケーブル曲げ空間は本体寸法に含めない。上面操作部はflush、カメラ遮光部は内側可動を要求し、伸縮/pan/蓋の外部展開を設けない。

入力の座標はX左右、Y前面0から後方、Z足底0から上。安全側の内法予算はX±96.3、Y2.2-174.8、Z6.4-194.8。全ての区画はこの範囲内であり、区画同士と隔壁の直方体干渉はない。ただしケーブル、実部品、ねじ、コネクタ、工具、寸法公差を含む3D CAD干渉検査ではない。

## 音声と冷却を両立するための構造条件

ReSpeaker XVF3800 USB 4-Mic Array（XIAOなし、SKU101991441）は候補。公式1頁機械図にあるPCB Ø100、基板厚1.20、mic間隔66角を参照し、110 x110 x20の区画を確保。基板中心X0/Y65なら上面音孔候補はX±33、Y32/98。Seeedロゴがあるmic inlet面を上へ向ける。孔径、音道長、ガスケット、コネクタ向き、固定具、部品高さの実装公差はHOLD。区画上端から安全側内天面まで0.3mmしかないため、この予算は厳しく、積層公差と実高さを確認して下げる/区画を改める必要がある。20mmを部品実高として用いない。

音声区画はfan区画より上下で68.5mm離れるが、これは距離であり遮音dBではない。上部隔壁Z172.5-174と下部熱源隔壁Z103-106、低振動保持、音孔別ガスケット、封止配線導入を検討する。音声の5Wも箱内発熱へ含むため、音響隔離を理由に密閉して熱を閉じ込めない。導熱経路と音響漏れは同時に実験する。

4mic候補の数や間隔だけで遠距離認識/全帯域beamformingは保証しない。同一clock取得、チャネル位相、音道差、fan ON/OFF、TV音量、手や固定具での音孔閉塞を測る。初期はPTT/monoでも検証できる。音声はTVなどへ外部出力し、本体スピーカーの負荷や筐体共振は本予算に含めない。AECには再生参照/遅延の実確認が必要で、外部TV音を自動で完全除去すると主張しない。

物理MUTEは上面右X67/Y62付近の独立操作部案。市販基板のボタンと同じ位置/機能だと仮定しない。mic電源/clock/dataの遮断方式、DSP/DMA内の残音処理、buffer purgeと状態表示は回路・ソフト・実機で確認する。上面を押せるだけで物理遮断が実装されたとはしない。

## 電力と熱の再計算

APU45 + board/RAM12 + SSD5 + vision8 + audio5 + fan/control5 = **80W DC割当**。音声5Wは旧3Wからの置換で二重加算しない。DC変換効率90%仮定で箱内保守熱枠80/0.9=88.889W、追加DC損失8.889W。実消費/瞬間peakではなく、外部USB負荷は初期無給電か別予算、外部ACアダプタ損失は箱内から除外。

空気密度1.2kg/m³、比熱1005J/kgK、温度差10Kのエネルギー収支で最低流量26.534m³/h。係数2の暫定検討点53.068m³/h。左右100 x90の吸気域を各開口率50%とすると自由面積45cm²ずつ（合計90）、後部160 x84の排気域は自由67.2cm²。検討点で平均流速は吸気1.638m/s、排気2.194m/s。これらは実fanの動作点を保証しない。filter/guard/duct/基板の圧損、逆流、埃、fan停止時の停止動作、認識中の回転変化と騒音を測る。

周囲上限26°C、表面45°C未満、測定余裕1°Cの単純なスクリーニング不等式はRθ <18/88.889=0.2025K/W。これは筐体表面の実温度保証でもCPU放熱器単体の仕様値でもなく、局所温度と接触材質/条件の実測が必要。120W等の電源枠を別途比較しても、本案で電源型番を発注指定したことにはならない。
