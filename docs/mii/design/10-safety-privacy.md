# 10 安全・プライバシー

## 1. IR 眼安全

- 850 nm LED、放射 3 W/Node、ビーム 90°、パルス駆動（デューティ ≤ 10%）。IEC 62471 の**免除群（Exempt）**に入れることを設計目標にし、放射輝度・放射照度を試作で実測（20 cm 距離、最悪ケース＝連続点灯故障）。
- ソフト制御だけに依存しない: **ハード電流制限＋watchdog（トリガーが来なければ消灯）＋熱遮断**。
- 転倒（IMU）→ IR/レーダー送信停止。Head の光学窓に手が近い（radar 近接 < 20 cm）→ IR 出力を 1/10 に。
- 子どもが Head を覗き込む前提で設計する（高さ 1.0 m は子どもの目の高さ）。

## 2. レーダー

60 GHz、送信出力は各国の免許不要帯の上限内（日本 ARIB STD-T73/T108 系、米国 FCC Part 15.255、EU ETSI EN 305 550）。人体への曝露は ICNIRP 以下（距離 0 でも）。TDM で平均出力はさらに低い。

## 3. 転倒・機械

- Column: 水平力 4.8 N まで静的に耐える。ペットや子どもが押す前提で**床ねじ止めオプション**と壁固定金具。
- ケーブル引張で倒れないよう、ベース側でケーブルを固定（ストレインリリーフ）。
- Head 回転部に指を挟まない隙間（< 4 mm or > 25 mm）。
- 表面温度 ≤ 45 ℃。

## 4. プライバシー（RockstarOS の権限で縛る）

| データ | 既定 | 本人が許可すると |
| --- | --- | --- |
| 生映像（NIR/RGB） | Hub の REALTIME 内で骨格・頭・物体に変換し**保存しない**。Hub の外へ出さない | 録画（Work の明示要求。例: ゴルフのスイング動画）は Receipt に残る |
| 骨格・頭 | Hub 内。遠隔プレイでは相手へ送る（映像は送らない） | — |
| 顔埋め込み（本人認識） | Hub 内の暗号化領域。account に紐づく。cloud へは埋め込みを送らない | 複数の mii で同じ本人を認識するため、埋め込みを account 経由で同期（E2E 暗号） |
| 音声 | ウェイクワード「ヘイ、エヴァ」までは Hub 内。以降は Eve（cloud or local LLM）へ | — |
| Room Model | Hub 内 | 建築家・施工者への共有は明示許可 |
| 来訪者（Slot の外向き） | 「人がいる」「顔」だけ。保存しない | 録画は本人の許可＋録画中サイン点灯 |

- **録画中サイン**: 外向き Slot と、録画を許可したときの全 Node で点灯する可視 LED（意匠に組み込む。PDF の黒い帯の端に細い白線）。日本の個人情報保護法・米国の州法（イリノイ BIPA 等の生体情報法）を task 20 の法務欄に。
- 物理遮断: Head に**機械式シャッター**（レンズ窓を物理的に閉じる）を付ける。R5 の「独立物理遮断」要求を継承。閉じた状態は Hub が検知し、presence は radar だけで継続。
- 子どものプロファイル: 保護者の account 配下。骨格は保存しても顔埋め込みは保護者の許可のみ。

## 5. 投影の安全

- レーザー光源の投影エンジンはクラス 1（IEC 60825）製品を選ぶ。
- 床投影で段差・階段を隠さない（Room Model の「危険領域」には描画しない）。
- 激しい動き（剣道・ダンス）のとき、安全領域の外（壁・家具）へ近づいたら警告を描く。

## 6. 法規（task 20 で調べる）

電波（レーダー）、光（IR・レーザー投影）、電気用品（PSE / UL）、EMC、PoE、建築埋込（Puck/Slot の防火・施工）、プライバシー表示。
