# 案 D — ライトフィールド卓（既製品を買って Spatial Core に繋ぐ）

一言: **一番早く「裸眼 3D の卓」を見られる案。** Looking Glass（27"/32"/65"）か Sony の空間再現ディスプレイを卓に置き、4 Node の手・目の追跡で操作する。自社で光学を作らないので試作は「買って繋ぐ」だけ。

## 1. 絵

```mermaid
flowchart LR
  N[Node ×4 手・頭] --> HUB[Hub]
  HUB -->|視点群 or 追跡視点で描画| LF[ライトフィールド画面<br/>（Looking Glass 32" 等）]
  HUB -.-> SRD[Sony SRD<br/>（一人・視線追跡）]
```

## 2. 何が見えるか

- Looking Glass: 画面の手前後 数 cm の奥行きに、**視野円錐（約 50°）の中で**複数人が同時に裸眼 3D を見る。画面の「中」に浮く感じ。画面の外・空中には出ない。
- Sony SRD（ELF-SR2）: 一人の目を追って左右別画像。27" で奥行きの感じは強いが一人用。

## 5. 今日作れるか

**◎ 買うだけ。** 1 週間で「分子を手で回す」デモが動く。価格は 02（27" 約 $10,000、65" 約 $20,000 の公表例）。

## 6. 設計書との差

05 章の Tier 表に「eye-tracked light field」として載っている。既製品なので Display Bus は不要（HDMI/DP）。

## 7. 位置づけ

- **製品にはしない**（画面が見える、サイズに対して高い）。
- **判断用のデモ**として最適: 本人が「画面の中の 3D」と「空中の 3D（案 B）」と「本物の体積（案 C）」を同じ週に見比べられる。20 章の試作計画で「1 台借りる／買う」を提案。
