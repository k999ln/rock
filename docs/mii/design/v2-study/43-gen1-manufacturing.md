# 43 製造・試験・品質 — 工場に発注できる形にするための、まだ無かった部分

本人の最初の指示は「工場に発注できる設計書」。31〜37 は「何を」、38〜42 は「どう動く・何を守る」。ここは「どう作って、どう確かめて、誰に頼むか」。

## 1. 共通化 — 認証と金型を 1 回にする

```text
  共通基板 ×3                              筐体 ×4（金型は別）
  ┌ 警報基板（煙・熱・CO・サウンダ・426 MHz・MCU・電池）→ 検定 1 回、C/D/A/E 共用
  ├ センサー基板（魚眼・ToF・LWIR・レーダー・マイク・環境）→ D/A/B/E 共用（E はステレオ追加の派生）
  └ 電源・無線基板（AC-DC は W 違い・技適済みモジュール）→ 3 サイズ
  SoM はソケット（RK3576 / RK3588 / Orin を差し替え）
  光学: エンジン＋チルト台を 1 ユニット（A/B 共用、E は固定 2 台）
```

| 共通化で減るもの | 数字 |
| --- | --- |
| 検定 | 4 モデル × ¥148,100 → **1 回**（(b) 案なら。(a) 案でも共通基板で型式の派生申請 ¥49,300） |
| PSE 適合性検査 | 電源基板 3 サイズ → 3 回（¥950,000 ×3）→ **PSE 済み AC-DC モジュールを部品にして 0〜1 回**を登録検査機関に相談 |
| 技適 | 認証済みモジュールで 0 回、426 MHz のみ 1 回 |
| 金型 | 共通の取付ベース（板金、金型不要）＋ 筐体は A/D で外径 Ø460/Ø390 の 2 系、B Ø300、E Ø520 → キャビティ 4 系 × 3 部品 ＝ **12 個、$100k〜300k**。最初は A と D だけ金型（6 個、$50k〜150k）、B/E は切削・SLA の 100 台まで |

## 7. 工場審査（検定第 2 試験）に要るもの

検定は製品だけでなく**工場の検査設備・製造工程・社内検査体制**を審査する（research-gen1-bom §3 制度メモ）。→ EMS に任せる場合でも、**自社に品質管理責任者 1 名**と、煙室の全数試験設備（試験煙・測定）を工場に置く。ISO 9001 が無い場合の技適加算（+¥60,000）と同様、検定でも体制が問われる。これは「人がやる」側（42 §6）。
