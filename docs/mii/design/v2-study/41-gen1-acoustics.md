# 41 音 — 85 dB の警報、ゲームの音、天井から人の声を聞くこと、ファンの音

天井中央の 1 枚は部屋の全員から等距離で、音の置き場としては最良。問題は 4 つ: 法定の警報音を拡散カバー越しに出す、ゲーム・Eve のスピーカーと同居させる、自分のファンと自分のスピーカーの音の中でマイクを使う、天井の残響。

## 1. 法定の警報音

| 市場 | 要求 | 設計 |
| --- | --- | --- |
| 日本 | 70 dB 以上 @1 m 前方・1 分以上（市販品は 87〜90 dB） | 圧電サウンダ 90 dB@1 m、**専用の開口**（直径 12 mm ×4、カバー外周）。拡散カバーの内側に閉じ込めない |
| 米国 | 85 dB @10 ft（3 m）≈ 95 dB @1 m | 同サウンダを 2 個、または 100 dB 級 1 個。音声告知（種類・場所）はスピーカー側（UL 217 は音声の併用可） |
| 520 Hz 低周波 | NFPA 72 で難聴者向け、住宅では任意。520 Hz は小型圧電では出ない | **スピーカー 5 W ×2 で 520 Hz 方形波 75 dB@枕元**を出せる（寝室の B・A）→ 差別化。UL は Temporal-3 パターン |
| CO | T4 パターン（4 連音） | MCU 側 |
| 独立性 | サウンダは警報 MCU 直結。スピーカー経由の音声は SoM が生きている時だけの「追加」 | 38 §1 |
| 消音 | 本体ボタン（脚立不要にするため**リモコン・声・app でも可、ただし 15 分で監視復帰**） | 省令 |

サウンダ部品: Murata PKM22EPPH4007（85 dB）は在庫 19・再入荷なし（research-gen1-bom 8A）→ 後継を選定（TDK PS1240 系、Mallory 等）。1,000 台の調達は EVT 前に確定。

## 2. スピーカー

| 項目 | 設計 |
| --- | --- |
| 構成 | フルレンジ 2 インチ 5 W ×2（Dayton CE48-4 €7.95 級）、外周の対向 2 点。背面容積は筐体の外周リングを利用（0.3 L ×2） |

| 熱 | ファンの排気側に置かない（コーン材の劣化） |

## 3. マイク — 自分の音の中で聞く

| 課題 | 数字 | 対策 |
| --- | --- | --- |
| ファン騒音 | Aladdin X2 Light 32 dB@1 m。マイクはファンから 10 cm → 50 dB 級の近接騒音 | ファンから最遠の外周にマイク、ゴムで防振、ファンの基本周波数（40 mm で 80〜100 Hz ＋ 羽根 7 枚 → 600〜700 Hz）をノッチ。SoM は回転数を知っているので適応ノッチ |
| 自分のスピーカー | 85 dB の音楽中に声を聞く | AEC（エコーキャンセル）: SoM が再生信号を知っている。4 マイクのビームフォーミングで話者方向へ |
| 天井の残響 | 2.4 m 天井・4.5 m 室の RT60 0.4〜0.6 s | 残響に強いウェイクワード（既製: Sensory/Picovoice 級）＋話者 ID は 2 s チャンク |
| 距離 | 立位の口まで 1.0〜1.5 m、床に座ると 2 m | 遠距離 4 マイク（ReSpeaker 級、A$92 の評価品、量産は MEMS ×4 直付け） |
| 投影エンジンの音 | カラーホイールは無い（LED-DLP）。DMD のミラー音は無視できる | — |
| 警報中 | 95 dB のサウンダのそばで声は聞けない | 警報中は声の受付を止め、ボタン・app のみ |

## 4. 音で分かること（見守り）

| 音 | 使い方 |
| --- | --- |
| 警報音（他社の住警器） | 426 MHz で連動できない他社機の「音」を聞いて家族に通知（連動の代替、鳴動はしない） |
| ガラス割れ・大きな衝撃 | 転倒の裏付け（カメラ＋レーダー＋音の 3 系統） |
| 咳・いびき | 健康の参考値（医療表現はしない、42 章） |
| 無音の長さ | 在室なのに長時間無音 → 見守りの注意 |

## 5. 聴覚障害・高齢者

- 警報時に照明を**白 100% 点滅**（NFPA 72 のストロボ相当、日本は任意）。
- 床・壁に「火事」「CO」の大文字を投影（A/B/E）。
- 音声告知は日英、話速を落とす設定。

## 6. 試験

無響箱: サウンダ 90 dB@1 m（JP 70 以上）、95 dB@1 m 相当（US 85@10 ft）、1 分連続、電池下限電圧で。スピーカー周波数特性 150 Hz〜15 kHz ±6 dB。マイク: ファン全速・音楽 80 dB 再生中にウェイク率 95%（1.5 m・正面）、話者 ID EER ≤ 5%（世帯 5 人）。騒音: 筐体 1 m で ≤ 30 dB（投影 ON）、≤ 22 dB（照明のみ）。
