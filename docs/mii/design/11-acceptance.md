# 11 受入試験

すべて**実測**で合否を出す。理論値・QEMU・単体テストの合格を実機合格と呼ばない（AGENTS.md §7）。

## 1. Node 単体（出荷検査）

| ID | 項目 | 合格 |
| --- | --- | --- |
| N-1 | 露光 skew（PTP 基準、ストロボ） | ≤ 100 µs |
| N-2 | NIR 120 fps 連続 1 時間、フレーム落ち | 0 |
| N-3 | IR 放射・眼安全（20 cm、連続点灯故障時） | IEC 62471 免除群 |
| N-4 | レーダー出力・周波数 | 各国規制内 |
| N-5 | 消費電力 | ≤ 12 W 平均 / 20 W ピーク |
| N-6 | 表面温度（25 ℃環境、1 時間） | ≤ 45 ℃ |
| N-7 | 転倒検知 → IR/レーダー停止 | ≤ 100 ms |
| N-8 | 機械式シャッター閉 → 映像なし、presence は radar で継続 | 動作 |

## 2. 追跡（4 本、基準部屋 4.5×4.5 m）

| ID | 項目 | 合格 |
| --- | --- | --- |
| T-1 | 関節位置誤差（中央で、モーションキャプチャ or 既知ターゲット比較） | ±10 mm（RMS） |
| T-2 | 頭（両眼中点）誤差 | ±10 mm |
| T-3 | 遮蔽: 腕を背中に回して Node 1 から消える → 骨格が消えない | 消失 0 フレーム |
| T-4 | 片足立ちで 2 本から見えない → 補完 | 同上 |
| T-5 | 竹刀先端（マーカー付き）速度 10 m/s での軌跡 | 連続（フレーム飛びなし） |
| T-6 | motion-to-photon（頭 → ViewerPose 出力） | ≤ 12 ms |
| T-7 | 複数人 2 名で viewer の取り違え | 0 回 / 10 分 |
| T-8 | 校正: ターゲット一周 → 再投影誤差 | ≤ 1.0 px、所要 ≤ 2 分 |

## 3. 本数可変

| ID | 項目 | 合格 |
| --- | --- | --- |
| S-1 | 1 本: 頭位置の奥行き誤差（radar 併用） | ±50 mm |
| S-2 | 2 本（対角）: 両眼中点 | ±15 mm |
| S-3 | 4 → 3 本（1 本の電源断）: 追跡の継続、quality の降格通知 | 中断 ≤ 1 フレーム、通知 ≤ 2 s |
| S-4 | 増設校正（4 → 5 本目） | ≤ 1 分、既存の誤差が変わらない |

## 4. 表示（Gen1 投影）

| ID | 項目 | 合格 |
| --- | --- | --- |
| D-1 | motion-to-photon（頭 → 壁の像、240 fps カメラ） | ≤ 30 ms |
| D-2 | 両眼中点（表示に使う値） | ±10 mm |
| D-3 | 投影面の幾何誤差（壁の角、格子） | ≤ 5 mm |

| D-7 | 影回避: 本人の影の中に重要物が置かれない | 動作 |

## 5. Demo（最初に作るもの、チャット回答 65 §40 を採用）

1. 中央に立つ → 3D 骨格が出る → 体を回す → 骨格が 360° 回る。
2. 片足を上げる → 2 本から見えなくても補完。
3. 腕を背中へ → Node 1 で隠れても消えない。
4. 目線を左右へ → 仮想の立方体で運動視差。
5. ヨガ: 青＝理想、白＝自分、赤＝ずれ。
6. ツイスター: 床の位置ではなく空間座標のターゲット。

Demo 1–4 が通れば Gen1 の追跡と表示は成立。5–6 はサービス書式（docs/services/）で書いてから。
