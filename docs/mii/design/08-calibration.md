# 08 校正（部屋・Node・表示・本人）

校正は「置いたら勝手に合う」が目標。本人の作業は**ターゲットを持って部屋を一周する 2 分**まで。

## 1. 工場校正（Node 単体）

| 項目 | 方法 | 保存先 |
| --- | --- | --- |
| カメラ内部パラメータ K, D（NIR・RGB） | チャートで標準手順 | Node の SE / NVRAM |
| NIR↔RGB の相対位置 | 同上 | 同上 |
| レーダーのアンテナ位相・取付オフセット | コーナーリフレクタ | 同上 |
| マイク位置 | 既知音源 | 同上 |
| IMU | 静止・6 面 | 同上 |
| 露光 skew（PTP 基準） | ストロボで実測、≤ 100 µs を**検査票に記録** | 出荷記録 |

## 2. 設置校正（Node 間の外部パラメータ R_i, t_i）

1. 本人が **校正ターゲット**（直径 30 mm の NIR 反射球 3 個を 300 mm 間隔で付けた棒。製品同梱）を持ち、部屋の中央で持ち上げ、ゆっくり一周＋上下に振る（約 60 秒）。
2. 各 Node が球を検出 → 対応点から相対姿勢を解く（球の既知間隔でスケール確定）→ Bundle Adjustment。
3. 世界座標の原点・向き: 床面は**床に置いたターゲット**で Z=0 を取り、基準壁は投影エンジンの位置（または本人が指差した壁）で +Y を決める。
4. 合格: 再投影誤差 ≤ 1.0 px、球間距離の誤差 ≤ 3 mm。不合格なら Eve が「Node 3 をもう少し内側に向けて」と言う（視野の重なり不足を自動判定）。
5. 結果は Hub と各 Node の SE に保存。Node の IMU が設置後の動き（> 0.5°）を検知したら「校正のずれ」を警告し、**自己再校正**（人の骨長を拘束にしたオンライン BA）を背景で回す。

増設校正: 新 Node を繋ぐと、既存 Node と新 Node の両方に見えるターゲット or 本人の骨格で新 Node だけを解く（既存は固定）。1 分。

## 3. 部屋校正（Room Model）

- RGB 魚眼＋NIR で平面検出（床・壁・天井）。Pro は Depth 1 本で「部屋の 3D 基準形」。
- レーダーは occupancy / 動体のみ（壁の精密メッシュは作らない）。
- 家具は意味理解（Semantic AI 30 Hz）で「机・ソファ・ヨガマット」としてラベル付きの箱で持つ。遊びでは足場・障害物になる。
- 出力: 壁・床の平面方程式、投影面の四隅、安全領域（人が動ける床面）、ドアの位置。

## 4. 表示校正（投影エンジン）

1. 投影エンジンから**グレイコード／位相シフトパターン**を投影し、各 Node の RGB/NIR カメラで撮る → 画素↔世界座標の対応 → 投影の K_p, R_p, t_p とレンズ歪み。
2. 壁と床の継ぎ目でメッシュワープを作る（平面でない壁も可）。
3. 色・輝度: 白・灰・RGB のパッチを投影し、Node の RGB で反射率を測って補正（壁色の補正）。
4. 遅延: 投影に時刻コードを出し Node で撮って**実測**（D-1 の内部版）。
5. 合格: 幾何誤差 ≤ 5 mm（壁 3 m 距離）、遅延の実測値を記録。所要 2 分、無人。

## 5. 本人校正

- 初回 10 秒: 正面に立つ → 両腕を広げる → 左右を向く。骨長・身長・眼間距離（IPD の既定 63 mm を顔で補正）。
- account に保存（別の mii / 将来の端末でも同じプロファイル）。
- 顔埋め込みで本人認識 → viewer に選ぶ（10 章: 埋め込みは Hub 内、生画像は保存しない）。

## 6. 校正の状態機械

```text
UNPAIRED → PAIRED(未校正) → EXTRINSIC_OK → ROOM_OK → DISPLAY_OK → READY
                ▲              │（IMU 動き > 0.5° or 再投影誤差 > 2 px）
                └──────────────┘ 自己再校正 → 失敗なら本人へ「ターゲットで一周」
```

READY でなくても **presence（人がいる・どこにいる）は常に動く**（安全のため）。
