## 2. 比較条件と教材

| 条件 | 学習・当日の表示 | 共通部分 |

工業部品の断面読解に入る前の**幾何学的な基礎課題**。立方体の三角形／四角形／五角形／六角形断面を4問とし、A/B/Cは軸の入替え・鏡映で同型にする。答えの符号は変わる。同じ難度を狙った設計であり、教育測定上の等価性・職場での技能転移は未検証。

当日は切断平面と辺の符号を見て、(1)断面頂点数、(2)切断される辺、(3)輪郭を描いて辺の巡回順を書く。各1点、1問3点・1条件12点。輪郭は開始位置と時計／反時計を問わない。紙の図と巡回記号が食い違えば記録者2名で確認し、解けていたことを後から推測しない。自動採点は転記された記号を採点するため、図そのものの目視確認は別に必要。

翌日は切断位置を少し変えた転移課題。**全条件とも同じ紙形式、端末・投影・ヒントなし**。前日の解答や正答を見せず、理解が翌日保持されたかを測る。同じ形式の反復による練習効果は残る。実技能の保持や長期効果へ一般化しない。

## 3. 事前固定と進め方

1. 8人の成人へ目的・任意参加・中止可能・録画しないことを説明する。施設が同意を別管理し、票には名前・メール・所属・顔・声・個人対応表を入れない。参加者がP01〜P08のカードをくじで取り、翌日持参。本人照合に顔認証を使わない。
2. `init`で空欄の実施用ディレクトリを作る。割付は6通りの順序を各1人＋2通りを追加し、方式×順番／方式×教材がそれぞれ2〜3人になるよう固定。8人では完全均衡にならない。結果を見て割付・成功条件を変更しない。
3. 進行者1名＋観察記録者1名を基本とする。試験前にスタッフだけで読みやすさと採点一致を確認し、教材を変える場合は別版として全条件を再生成する。
4. 各条件で共通練習90秒（中央で切る四角形の1例）、本問4問を各最大90秒。問題提示開始から回答終了までを手元の時計で測る。条件間は2分休憩。必要な休憩は優先し逸脱として記録。問題順は割付CSVに従う。所要は説明・休憩込みで概ね30〜40分の運用枠とする。
5. 参加者の依頼があった時だけ、30秒以後にヒント1「平面が横切る辺を一つずつ探してください」、60秒以後にヒント2「隣り合う面をたどって、交点を一周つないでください」。各1回、追加説明は`extra_teaching`。正答・形の名称は教えない。
6. 翌日、各条件の終了から20〜28時間（24時間を目標）に紙の転移4問を行う。条件順は前日と同じ事前割付順。各問最大90秒、ヒント0。実際の間隔を記入し、窓外は補足記録に残し主要比較には入れない。この窓は試験運用の仮定であり、科学的な境界値ではない。
7. 全員の翌日分が終わってから正答を示す。自動採点前に転記と輪郭を2人で照合。集計後に教材と方式の交絡、順序、欠席・技術失敗を確認する。

スマホは手持ち、wall/gen1は同じ紙の置き場を使い、視距離・投影幅・照度を設置票へ記す。サイズ差を消した「純粋な光学効果」の試験ではなく、実利用方式の比較。wall対gen1が頭部追従の追加効果を見る主な対照となる。眼鏡が日常必要な参加者に外させない。「裸眼」は専用ヘッドセット等を要しない設計要求であり、視力矯正を制限する意味にしない。

## 4. 計測の定義と欠測

| 記録 | 定義・単位 | 未測定時 |
| --- | --- | --- |
| 視線切替 | 表示面↔解答紙の切替を観察者が数える。到着側を約0.3秒以上見るたびに1回。開始位置は数えない。別方向を見る動きは数えない | 空欄。頭位置カメラを眼球追跡装置と呼ばない |
| 時間 | 問題表示→回答完了、秒。90秒で打切り。設置・学習・休憩と分ける | 空欄。打切りはstatus=`timeout`・90秒 |
| ヒント | 上記の標準文を出した回数0〜2。翌日は0 | 空欄は未確認、0は観察済み0回 |
| 即時／翌日正答 | 頂点・辺集合・巡回の3点×4問。無回答は完了／時間切れを明記した場合だけ0点 | 未実施の空欄を0点にしない |
| 設置負担 | 設置、校正、撤収の分数、人数、占有面積、ケーブル数、工事の有無 | setup.csvへ別記、空欄を推定しない |
| 施設回答 | 次回日程、予算上限、購入意向、実提案、入金を別列 | 未回答は空欄、意向から入金を作らない |

視線切替は人による観察値。スタッフ練習で2人のカウント差を確認し、曖昧な場合は欠測とする。録画を前提にしないため精密な眼球運動計測ではない。

仮説は「8人中6人以上で、Gen1の当日視線切替**合計**がスマホ・壁面投影の**両方**より少なく、当日・翌日の得点が両方以上」。視線切替/分、秒数、ヒント数も並記し、短時間で諦めただけの見かけの改善を確認する。**8人全員に比較可能な全条件が必要**。7人だけ測って6人成功を6/7として合格にしない。失踪、技術失敗、追加指導、記入不足は主要比較の未完として残す。

8人の探索試験は効果の確証でも市場需要の証明でもない。6/8は依頼にある商業仮説を操作可能にした暫定基準で、有意差・必要標本数・購入の証拠を意味しない。施設の「次回希望日」「予算上限」は回答記録、提案送付や入金は別の証拠が必要。本キットは証拠参照を受け付けるが実在を外部照合しない。

## 5. Gen1を実参加者へ使う前の条件

- 既製の手持ち投影機をその取扱条件内で、台・既存コンセント・着脱ケーブルにより設置する。壁・天井の工事、新規光源やレーザー装置の製作をしない。
- 壁の実際の描画長方形の幅・高さをmで測る。`manifest.display`へ入力。原点は長方形中心、+x右、+y上、+z室内／観察者側。カメラ座標からこの座標への校正が必要。画像拡大・台形・ブラウザ倍率を変更したら再校正。
- trackerが両眼中点をmで出し、既知の位置を使って精度を測る。顔検出結果だけ、画面上の2D座標、マウス、fixtureを実頭位置としない。
- task21の左右1m移動で破綻なし、物理motion-to-photon **50ms未満**、幾何誤差5mm以下、快適性、転倒／眩しさ等の設置確認を測って`gen1_readiness`へ記録する。許可の代わりにしない。計測手順・機器・不確かさをローカル試験記録で保持する。
- 既存製品基準D-1 **30ms以下**、D-2 **±10mm**、D-3 **5mm以下**、D-4 **10人中8人**、D-5 **90°/sで破綻なし**は別々に未判定のまま保持する。今回の8人比較でD-4を合格にしない。ブラウザfpsや入力の古さを物理遅延へ読み替えない。
- tracker入力が100msを超えて古い、欠落、異常値の場合はGen1像を止める。再開前に中断理由を記録し、同じ問題の再試行を主要結果へ上書きしない。気分不良・眩しさ・危険動作で直ちに中止する。
