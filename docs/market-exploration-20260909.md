# Rock — ゲーム資産市場・予測市場の検討メモ

2026-09-09 / 構想段階・未承認。実装・実資金・公開運営の指示ではない。

利用者の補足により、構想の中心を「自動化で時間/収入の余地を作り、ゲームと現実のさまざまな挑戦を選べる人を増やす」と明記する。賭け/投資だけが目的ではない。共通Walletでこの接点を支える方針は維持し、利益・通貨の値上がり・地球規模の効果を実証済みにしない。

GTA Vの株式市場はゲーム内経済の例として理解する。[Rockstarの修正記録](https://support.rockstargames.com/articles/VwB3r6tbVAvoZQfSWGG0I/gtav-title-update-1-19-ps3-xbox-360-1-05-ps4-xbox-one)にも市場への言及がある。一方、今回確認した [GTA VI公式紹介](https://www.rockstargames.com/VI)では現実の資金や外部Wallet連携を確認できていない。新作への期待を仕様として採用せず、正式な接続条件が出た時点で適合確認する。

## 1. できることを分ける

技術的にはOSの任意の入口から扱える。ただし次の3つは別機能で、同じWalletを使うだけで自動的に成立するものではない。

| 機能 | 何を扱うか | 今の設計との関係 |
| --- | --- | --- |
| ゲーム通貨交換 | Walletの資金と指定ゲーム通貨を条件付きで交換 | RQ13の対象。未実装、方向/レート/本番条件未決 |
| ゲーム資産売買 | プレイヤー間で通貨・アイテム等を売買 | 追加案。所有/譲渡権、発行量、売買成立、流動性、資産消失時の扱いが必要 |
| 予測市場 | 将来の出来事の結果に応じて支払いが変わる契約を売買 | 追加案。結果判定、担保、注文/清算、異議・取消、不正取引対策が必要 |

予測市場は単なる「コインの値上がりを待つ」投資とは異なる。米CFTCはイベント契約を出来事の結果に価値が依存する金融契約として説明している。結果を外せば投入額を失う場合があり、利益や安全性は保証されない。[CFTC公式](https://www.cftc.gov/LearnandProtect/PredictionMarkets)

Polymarketは市場ごとに判定情報源・終了条件・曖昧な場合の扱いを定め、結果提案と異議申立てを経て決着する。Walletの残高をAIの判断だけで増やす仕組みではない。Rockで同方式や特定チェーンを採用すると決定したわけではない。[Polymarket公式・結果確定](https://docs.polymarket.com/concepts/resolution)

## 2. Rockに合わせた方向性（提案）

Rockがまず強くするのは「複数ゲームの資産を取り違えず管理し、条件を確認して接続・交換できる共通Wallet」。ゲーム資産の利用場面が増えれば、この共通窓口の利便性が高まる可能性はある。ただし需要・流動性・作者の発行/変更権・サービス終了リスクを検証する必要があり、通貨に値段が付く未来や価格上昇を前提に事業収益を計算しない。

独自の市場運営と、適法な外部市場への接続は別の選択肢。外部接続だけなら無条件に規制対象外になる、とは考えない。どちらも現時点では採用しない。

OSは表示・本人承認・権限管理、別の市場サービスは注文・判定・清算を担当する構成が候補。自動化収益のWalletを市場資金へ自動移動せず、明示した割当ての範囲だけを扱う。ATMは独立、ゲーム/市場障害でHubの基本操作を止めない。市場・ゲーム料金は未定であり、ATM自社手数料0の方針を他機能へ拡大しない。

持ち歩く端末の価値は価格確認回数だけで判断せず、必要な承認や取引状態を短時間で把握できるかで測る。AIによる自動賭け、レバレッジ、借入、自動化収入の再投機は現在の案に含めない。

## 3. 本番提供の前に必要な判断

「ゲーム内通貨だから賭博や金融の規制から外れる」とは言えない。例えば英国当局は、現金や価値のある物に交換できるゲーム資産を金銭相当として扱い、それによる賭博提供には許可が必要だと説明する。英国での説明であり全世界へ同じ法的結論を当てはめない。[Gambling Commission](https://www.gamblingcommission.gov.uk/licensees-and-businesses/guide/page/digital-and-virtual-currencies)

日本の警察庁は、海外で合法なオンラインカジノでも日本国内からの賭博は犯罪になると注意している。これはRock案の法的分類を確定する資料ではないが、海外運営や名称の変更だけで解決しないことを示す。[警察庁](https://www.npa.go.jp/bureau/safetylife/hoan/onlinecasino/onlinecasino.html)

運営国・利用者の対象国/年齢、対象イベント/資産、換金/譲渡性、発行権、資金保管、必要な登録/許可、本人確認/資金洗浄対策、税務、利用限度/自己排除、利益相反/不正監視、異議・取消・廃止時の清算を、提供形態に即して専門家/提供者と確認する。未決のまま実資金へ接続しない。

## 4. 試作するなら最初の候補

別途承認された後、内部専用の架空イベントによる予測シミュレーションから始める案。無料配布・購入不可・譲渡不可・換金不可の実験点数だけを使い、景品・賞金・将来の換金権を付けない。現金Wallet、交換可能ゲーム通貨、ATMと台帳・権限を分離し、実資産へ移せる隠れた経路を作らない。

判定根拠、異議、取消、通信断、二重精算防止、点数の保存則を試験する。非換金なら全地域で無条件に合法という保証ではない。内部試作の成功を一般公開/実通貨運営の許可にしない。

現在の順番はOS稼働→共通Walletの複数owner基礎→ゲーム交換/作者SDK。市場案はOS稼働の必須条件へ入れず、採用・対象地域・運営方式を別途確認してから専用設計を作る。
