# RockstarOS Chat 操作性改善

日付: 2026-09-12

## 目的

SKY12で作成したSky Auto中心のChatを、デスクトップとスマートフォンで日常的に使える表示と入力操作へ整える。接続済みアプリの選択、依頼、担当の案内、最近の処理という既存の責任分担は変えない。

## 今回の変更

- 後続のSky統合で欠落していたChat専用CSSを復旧し、黒基調の会話面、横スクロールできる担当切替、固定入力欄、スマートフォンのsafe areaを再実装した。
- 一行入力を複数行textareaへ変更し、Enter送信、Shift+Enter改行、2000文字上限、送信後の自動スクロールを追加した。日本語IMEの変換確定では送信しない。
- 担当切替へ`aria-pressed`、会話本文へ`role="log"`を付け、依頼例を選ぶと入力欄へfocusを戻す。
- 最近の処理は完了、実行中、要確認、停止、受付済みを色とアイコンで分け、項目全体から保存済み履歴を開けるようにした。
- 接続済みの担当へ依頼した場合は、担当選択だけで終わらず、必要な入力、実行、結果、履歴保存の流れと既存の実行画面を同じChatスレッド内へ展開する。既存runnerとjob receiptを再利用し、Chat専用の裏口実行APIは追加しない。
- Sky接続の許可リストを既存4 jobだけからready担当へ広げ、サブスク顧問、法務受付、特許出願担当も本人別・一回接続の同じ契約でChatへ表示できるようにした。Fashion Brand Opsは既存のMCP session検証を通った場合だけChatへ表示する。
- 接続済みの役割数を初期案内へ表示する。会話内容はブラウザ保存しないため、法務・特許等の入力を新たな永続データにしない。

## 安全境界

Chatの返答は依頼先の選択と案内であり、実jobの実行・完了・売上を意味しない。第三者への送信、課金、送金、投稿、法的提出は今回の変更に含まれない。実行結果の正本は既存job receiptと履歴のままとする。

- `npm run typecheck`: 成功
- `npm run lint:product`: 成功
- `npm run sky:check`: 成功。Chatの操作属性とレスポンシブCSSが欠落した場合に失敗する検査を追加
- 実ブラウザ: デスクトップ表示で依頼例「記事を整えて」を選び、Enterで送信し、未接続担当の案内と自動スクロールを確認
- 実ブラウザ: 390 × 844 pxでheader、担当切替、依頼例、入力欄が横にはみ出さず、入力欄が下端に表示されることを確認
- 実ブラウザ: 記事編集役を1タップ接続し、「この原稿から無料版を作りたい」から処理カードを開き、サンプル入力、ブラウザ内処理、結果表示、`結果あり`状態、保存済みjob履歴まで確認
- 実ブラウザ: 法務受付を1タップ接続し、「契約書の内容を整理したい」から、注意事項と安全確認を含む法務受付runnerがChat内へ展開されることを確認
