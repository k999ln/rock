# Noah — 棚とパッケージ（選ばせない・組み合わせを考えさせない）

- 本人が言う一言: 「手動で 7 万個から選ぶのは非現実的」「最初はパッケージ化して、健康について考えてる人はこの agent、経理はこの agent」（11-19）「収益化できそうなやつ、これ。教育系使うならこれ」「1 つの仕事を最後までやる組合せ」「今動かせるもの」（11-20）「どっちもお願い」「全部任せる」（11-21）
- Goal（Eveが作る）: 目的＝カード 1 枚を選ぶだけで、1 つの仕事が最後まで終わる / 入力＝カードの「渡す物」（素材の型で決まる） / 期待成果＝カードの「受け取る物」と、合格条件の判定 / 予算上限＝無料枠、または本人の月の上限 / 要る権限＝カードの工程の先が宣言した権限だけ（カードは権限を足さない）
- Noaがつなぐもの: カード `noah-package/1`（新規）、取り込んだ系列（`noah_intake_families`）、家の端末の固定 adapter（`RECIPES`）、Noah の中の道具（`compositionCapabilities`）、工程の計画（`lib/sky-recipe-planner.ts`）、今の点数表（`lib/noah-recommendation-policy.ts`）、売れる型の最低額（`lib/sky-gig-offers.ts`）
- AMCの工程:
  1. カードの下書き（担当: 運営）— 合格条件: `parseNoahPackage` が通る（規則 20 個。合格条件が 1 つ以上。カードの文に、誘う語が無い）。
  2. 動かして確かめる（担当: 運営）— 合格条件: その審査者自身の、成功した実行が、直近 7 日にある。確かめた時の工程の中身を、サーバーが記録する。
  3. 載せるかの判定（担当: Noa）— 合格条件: `noahPackageListing` が `listed: true`（理由 8 つのどれにも当たらない）。
  4. 並べる（担当: Noa）— 合格条件: `rankNoahShelf` の結果のとおりに出る。切り替えが閉の間は、運営の順。
  5. 使う（担当: Work）— 合格条件: 各工程の成果が、次の工程が受け取る型に合う。本人の工程は、本人に残す。
  6. 検収（担当: Jev）— 合格条件: カードの合格条件が全部真。助言を含むカードは、決まった 3 つの条件も真。
  7. 見直す（担当: Spider と巡回）— 合格条件: 系列の握手・実行・取り下げの直後と、1 日 1 回、載せている全部のカードを判定し直す。
- Jevの合格条件: 運営が動かして確かめていないカードの表示 0 件。工程の中身が変わったカードの表示 0 件（次の握手まで）。5 人未満の実績の表示 0 件・並びへの使用 0 件。同じ入力に対する並びの違い 0 件。カードの文の、誘う語 0 件。専門家の確かめが無い、助言を含むカードの表示 0 件。カードを通じて増えた権限 0 件。
- 出力先: スマホ（`/noah/ready` の一番上の棚、タイムラインのカード）。Pro・mii でも同じ契約。phone でも可。
- Wallet: 棚とカードは 0 円。カードの工程の料金は、その先の料金のまま（カードは値段を足さない）。売値の目安は表示だけで、請求でも約束でもない。つなげる数は、無料 6 枚・有料 50 枚（値段は未定。既存の月額の型から選ぶ。新しい課金型は作らない）。
- hardware profile 依存: 全部。あなたの端末で動く工程があるカードは、端末が応答している本人にだけ出す。契約に機種の名前を書かない。
- 失敗時: 工程が動かなくなったカードは、理由を付けて棚から外す（本人には出ない。運営の画面に理由が出る）。検収に通らない成果は、本人に渡さず差し戻す。実績が無いカードは、運営の順のまま出す。
- 記録: カードの版と hash、確かめた時の工程の中身、載せていない理由。実績は、全員を合わせた数だけ（人数・接続・依頼・成果・また使った人・秒数）。見せた記録は、日・カード・位置の区分ごとの回数。本人ごとの記録は、履歴の利用に同意した本人の、カードごとの回数だけ。依頼と成果の本文、相手の URL、本人の ID を、集計の表に残さない。

## 決まり

- カードの名前と 1 行の説明は、運営の言葉。提供者の説明は、作り替えずに、別の段に出す。
- 並びに、学習したモデル・乱数・人気（回数そのもの）・売上を使わない。使うのは、つながる率・成果が返る率・検収に通る率・また使う率と、運営の順。
- モデルに頼むのは、札（受け取る物・出す物）の候補だけ。決まった語彙の外は捨てる。候補は、運営が確かめるまで使わない。
- カードは、何も実行しない。実行・課金・外部送信は、今の Broker・Wallet・Jev の gate を通る。
- 切り替えは全部、閉じたまま入れる（`NOAH_SHELF_PUBLIC`・`NOAH_SHELF_RANK`・`NOAH_SHELF_CHAINS`・`NOAH_SHELF_HOME`・`NOAH_SHELF_SEEN`・`NOAH_PLAN_LIMITS`・`NOAH_TRIAL_OPEN`）。開けるのは本人。
