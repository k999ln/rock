# Noah — 公開サイト診断と相談準備

- 本人が言う一言: 「残りの提携済み案件との組み合わせも進めて。条件が揃ったものからNoahに載せて」。
- Goal: 管理を許可された公開HTTPSホームページを実診断し、WordPress保守またはEC制作の相談準備を返す。紹介は本人の希望と現行案件条件に一致する場合のみ。広告予算・新規有料契約0。
- Noaがつなぐもの: Bot Appétit scan_page、AgenticCart check_store_readiness、既存CombinationLedger、登録済み媒体、既存ASP読取。固定接続先・操作・実測定義hash以外は実行しない。
- AMC: 公開・所有確認→外部診断→日本語の確認事項→希望に合う登録記事→広告主の本人申込→ASP注文/承認の実観測。既存15分の公開再判定と6時間のChrome取得を使う。
- Jev: 同意なしの外部呼出し0、私用/認証付き/クエリ付きURL送信0、診断失敗時の紹介0、期限切れ・提携解除・記事未確認の掲載/紹介0、第三者結果による任意操作0、広告主フォーム自動送信0、実成果の二重加算0。
- 出力: 診断の出典・日時・確認事項・相談準備票を共通Workへ保存。提供元Workerは公開URLの診断結果を最大24時間キャッシュし、相談本文を保持しない。Bot Appétitは公開履歴を持ちGoogle PageSpeed/Safe Browsingも利用する。
- Wallet: 無料診断の範囲のみ。AgenticCartの有料修正案は取得しない。利用者の購入代金・成果報酬・自社広告費を混ぜない。
- hardware: 既存Worker/DO。新D1 migrationなし。ASP読取は本人のMac/Chromeログインが必要。
- 失敗: 外部停止・料金要求・定義変更・利用上限は診断を止める。アカウント作成/課金/レート回避なし。再開可能な説明を返し成果を作らない。
- 記録: 匿名利用ID、用途、実行日時と実測定義hash、媒体・案件単位のASP成果。原文タグは変更せず、記事経由の成果は媒体集計でありNoahの個別利用者へ確定帰属しない。

WordPress診断はページの公開状態を確認するもので、バックアップ・内部更新・侵入被害の証明ではない。保守を必要とするWordPress管理者が新規相談を希望する場合だけ案内する。EC診断の低得点だけで制作を勧めず、本人が新設/改修を希望する場合だけ案内する。SEO/広告の掲載と流入、問い合わせと承認報酬を区別する。
