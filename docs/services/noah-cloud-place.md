- 本人が言う一言: 「ワンクリックで接続がされるように工夫してほしい」（11-20）「うちのクラウドを介する」（10-07）
- Goal（Eveが作る）: 目的＝本人の端末に何も入れずに、審査済みの Agent を隔離して動かす / 入力＝固定版（hash）、依頼文、承認済みの上限 / 期待成果＝既存 Work の成果と使用量 / 予算上限＝無料枠、または本人の月の上限 / 要る権限＝その版が宣言した権限
- Noaがつなぐもの: `noah-terminal/1`、`noah-isolation/1`、`/api/noah/runner` と同じ受け渡し（取りに来る・lease・heartbeat・finish）、モデルの中継、既存 Work、Wallet の予約
- AMCの工程:
  1. 受付（担当: Broker）— 合格条件: 利用権・上限・版の固定を確かめた。
  2. 隔離環境の用意（担当: Work）— 合格条件: owner ごと・仕事ごとに別の VM。
  3. 配置（担当: Work）— 合格条件: 配布物と依存の層の hash が固定版と一致。
  4. 実行（担当: Work）— 合格条件: 上限の内側で終わる、または理由付きで止まる。
  5. 回収（担当: Work）— 合格条件: 成果と使用量が Work に残り、隔離環境が消えている。
  6. 精算（担当: Wallet）— 合格条件: 無料枠の消費、または従量の明細に 1 回だけ載る。
- Jevの合格条件: 別 owner との隔離環境の共有 0 件。宣言外の host への通信 0 件。隔離環境の中の鍵 0 件。上限を超えた継続 0 件。停止後に残る隔離環境 0 件。同じ要求 ID の実行 1 回以下。結果不明の自動再実行 0 件。hash が合わない配布物の実行 0 件。上限額を超える予約 0 件。

- Wallet: 無料枠（候補: 1 人 1 日 10 回）。超えた分は si 使用料（実費＋30%、しきい値 1,000 円の後払い。[product-baseline.md](../product-baseline.md) の既存方針）。本人の月の上限で止める。運営全体の月の上限も置く。新しい課金型は作らない。
- hardware profile 依存: 全部（実行はクラウド）。
- 失敗時: 準備の失敗・時間切れ・上限到達・通信の拒否を分けて見せる。lease を越えた仕事は結果不明にし、再配送しない（runner と同じ）。
- 記録: owner、版 hash、隔離環境の種類、開始と終了、CPU 秒、メモリ、モデルの入出力トークン、通信した host、停止の理由。依頼と成果の本文は既存 Work にだけ置く。

## 作り

- 専用 Worker から Cloudflare Sandbox を起動する（[noah-cloud-operation.md](noah-cloud-operation.md) の専用 Worker と同じ置き方）。Web の本体とは別の配備にし、runner と同じ認証付き API だけで話す。
- Sandbox は 1 つが 1 つの VM。ファイル・プロセス・ネットワークは別。認証と回数制限は用意されないので、こちらで持つ。
- 外向きの通信は全閉から始め、接続要件の `egress` だけ許可する。モデル提供元の host は中継へ向ける。鍵は中継が付け、隔離環境には入れない。
- 実行の契約は `noah-terminal/1` をそのまま使う。モデルは host が渡す。OpenAI 互換の呼び出しを直接書いたコードは、外向きの中継で受けて同じ中継へ流す。
- place=`cloud` は本人の端末一覧（`noah_runner_devices`）には出さない。`noah_runner_commands` は「端末 1 台につき実行中 1 件」の一意制約（`noah_runner_one_claim`）を持つので、そのままでは並列にできない。同じ形の受け渡しを別の表で持つか、制約を place 別にするかは実装で決める。既存の表の意味は変えない。
- 上限の初期値は今の `LIMITS`（240 秒、モデル呼び出し 8 回、出力 2,048 トークン、入力 12,000 bytes、ファイル 12 個）。

## 費用の式

1 回 ＝ vCPU × 動いた秒 × $0.000020 ＋ GiB × 秒 × $0.0000025 ＋ GB × 秒 × $0.00000007 ＋ モデル（入力・出力トークン × 単価）。

定価は 2026-11-20 取得。ふつうの仕事で約 $0.001、上限いっぱいで約 $0.011（[設計書 §6](../noah-agent-market-design.md)）。Worker・Durable Object・ログ・通信量は別。箱の種類は実測で決める（候補: basic か standard-1）。

## 最初に測るもの

固定 adapter 13 件のうち、モデル無しか中継で動く物を使う。準備の秒数、最初の成果までの秒数、1 回の費用、同時 10 件での失敗数。結果をこの文書へ足す。
