## 決まり

1. 他人が作った Agent のコードは、画面・キーボード・マウス・ブラウザ・音・クリップボードが存在しない所でだけ動かす。行儀の約束にせず、作りで不可能にする。
2. 本人の端末のターミナルで直接動かさない（VM の外では、窓・音・クリップボード・権限ダイアログを出せて、ファイルも読める）。
3. 画面やブラウザが要る Agent には、専用の端末の中の画面を渡す。本人の画面は渡さない。
4. 本人が使っている端末そのものを操作する Agent（本人のスマホや Mac のアプリを代わりに操作する型）は受けない。mii では、Agent に空間の表示・カメラ・マイク・センサーを直接渡さない。Agent が返すのは成果と表示の依頼で、描くのと聞くのは RockstarOS。
5. 依頼は Work に入り、画面は元へ戻る。画面を開いていないと進まない実行を作らない。
6. 本人が要る時（許可・ログイン・人の判断）は、通知と「あなたの番」の一覧に出して待つ。前面に割り込まない。
7. 使っている最中の端末でのローカル推論は、既定で行わない（雲の中継か、端末が空いている時）。

## 面

| 面 | 手がかり（静的） | 動かす所 |
| --- | --- | --- |
| 無し | リモートの接続先だけ | 提供者 |
| ターミナル | 標準入出力で話す package・CLI・`noah-terminal/1` | 専用の端末の PTY |
| ブラウザ | `playwright`・`puppeteer`・`selenium`・`browser-use`・`chromium` | 専用の端末の中のブラウザ（画面なし） |
| 画面 | `pyautogui`・`pynput`・`xdotool`・`mss`・VNC・computer use | 専用の端末の中の仮想の画面。または誰も使っていない家の端末 |
| 本人の端末 | `osascript`・AppleScript・macOS のアクセシビリティ、Android のアクセシビリティ・`adb`・`uiautomator`、Windows の UI 自動操作 | 受けない |

手がかりは依存と import から読む。説明文だけで決めない。接続試験で、隔離環境の中から画面を開こうとした記録・ブラウザの起動・外向きの接続先を観測し、宣言と照合する。

## 観測（置き場所ごと）

| 置き場所 | 何を見るか |
| --- | --- |
| 提供者・雲 | 本人の端末では何も動かない。見るのは 5（閉じても進む）と 6（割り込まない）だけ |
| 家（Mac） | 実行中 100 ミリ秒ごとの前面アプリと窓の一覧、合成入力の数、クリップボードの版、runner と VM の権限（アクセシビリティ・画面収録・自動操作の許可が 0）、入力の遅れ |
| 手元（Pixel） | 実行中に前面の activity が変わらない。アクセシビリティ・画面の投影・重ね表示・入力の注入の権限が manifest に無い。描画の遅れ、温度 |

リポジトリの検査（常に走る）: 隔離環境の起動引数に、`DISPLAY`・host の mount・host の network・特権が入っていないこと。runner と client の権限の宣言に、画面・入力・録画・自動操作が無いこと。

## のぞく

専用の端末のターミナル（次に、中のブラウザと画面）を、本人が見るだけの窓で開ける。既定は閉じている。見なくても進む。本人が代わりに操作する機能は、この契約には入れない。
