# Noah — Agentの評価とフィードバック

- 本人が言う一言: 「利用した人数を可視化、王冠ボタンで評価。Agentにコメントしてフィードバックをもらう」
- Goal（Eveが作る）: 公開Agentに対する利用人数・評価・個人の感想を見て、コメントと返信を残せる。予算0、既存の本人認証を使う。
- Noaがつなぐもの: 公開カタログ、Noah Runnerの実行完了記録、共通の本人ID・公開名、Agent別の評価/コメント台帳。
- AMCの工程: 公開Agent確認 → 集計/コメント閲覧 → 王冠/コメント/返信 → 保存結果確認。各操作はAPIの保存完了後に反映する。
- Jevの合格条件: 同一accountの票が2以上になるケース0、私有Agentの公開0、他者のコメント削除0、別Agentへの返信混入0、通信失敗での偽の0表示0、同じコメント再送の重複0。
- 出力先: スマホ/PCのAgent紹介と詳細の「みんなの声」。作者も同じ公開画面で読める。メール等の通知は送信しない。
- Wallet: 無料。評価と利用人数を課金・実行権限の代わりにしない。
- hardware profile 依存: ブラウザのみ。利用人数はNoah Runnerがサーバーへ返し受理されたrun成功記録のあるaccount数。接続だけ、待機、不明、失敗、閲覧、登録は数えない。
- 失敗時: 未取得は「—」、保存失敗は状態を変えず再試行。本人未確認なら共通accountへ。コメントには既存の公開名を使う。
- 記録: 王冠はAgent/本人/値/版/要求ID/時刻、コメントはAgent/本人/公開名参照/本文/返信先/要求ID/時刻/削除時刻。内部本人ID・実行本文・認証情報は公開しない。

## ローンチの範囲

- 閲覧は登録不要。王冠は既存認証のaccountにつき1票で、同一人物の複数accountを名寄せする機能は含まない。コメントには既存公開名が必要。
- 利用人数はNoah内の保存された実行完了記録による観測値。外部サービス単独利用、未同期のMac利用は含まない。本人名や仕事本文は人数集計へ出さない。
- 公開カタログのAgent/候補・実行対応Agentだけを対象にする。私有uploadや招待は対象外。
- コメントは1件1000字、本人あたり1時間20件。公開されることを送信欄に明記。親コメントへ返信し、自分の投稿を削除できる。作者確認のない「作者」バッジは付けない。
- 公開中Agentの削除されていない親コメントは通常タイムラインにも掲載。返信はAgent別のコメント欄に表示。
- 原文は自動評価・要約・創作せず、そのまま表示。合計/ページ送り・未取得/0件を区別する。
- 新規SQLは開発用に作成・ローカル検証のみ。本番migration・配備・切り替えを行わない。
