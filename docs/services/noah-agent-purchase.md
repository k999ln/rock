# Noah — Agent の売り買い（試用・つながってから払う・直した版の権利）

- 本人が言う一言: 「agentを買ったり売ったりできるマーケットプレイスとしても使えるようにして」（11-20）「より接続しやすく、より解約しやすく、開発者側も手数料を取られないように」（10-07）
- Goal（Eveが作る）: 目的＝Agent のカードから、試して、つながってから払う。作者へ分配する / 入力＝版、販売条件の revision、本人の支払い方法 / 期待成果＝有効な利用権と Passport、作者の売上の明細 / 予算上限＝表示した価格。従量は本人の月の上限 / 要る権限＝購入の確認（1 タップ）
- Noaがつなぐもの: `sky_commerce_offers`、`sky_commerce_orders`、`sky_commerce_sellers`、`/api/sky/commerce/[action]`、Stripe Checkout / Connect、`authorizedNoahRelease`、`noah_instances`、接続計画（[noah-one-click-connect.md](noah-one-click-connect.md)）
- AMCの工程:
  1. 条件の表示（担当: Wallet）— 合格条件: 価格、試用の残り、更新を含むか、返金条件、動く場所を、revision を固定して見せた。
  2. 試用（担当: Work）— 合格条件: 作者が決めた回数の内側。コードを利用者へ渡さない場所で実行した。
  3. 仮売上（担当: Wallet）— 合格条件: 価格と宛先をサーバーが決めた。
  4. 接続の確認（担当: Jev）— 合格条件: 疎通が通った。
  5. 確定（担当: Wallet）— 合格条件: 4 が通った注文だけ確定。通らない注文は仮売上を取り消した。
  6. 分配（担当: Wallet）— 合格条件: 既存の手数料計算と一致。
- Jevの合格条件: 接続の確認が通らない注文の確定 0 件。同じ本人・同じ Agent の進行中の注文 1 件以下。価格・宛先・手数料を client から採用 0 件。返金・紛争の後の新規実行 0 件。更新を含む条件で買った人が、審査済みの直した版を使えない 0 件。この版のみの条件で買った人が別の版を使える 0 件。手数料の計算の差 0（`marketplaceCommissionMinor`）。試用の上限を超えた実行 0 件。
- 出力先: カードと詳細の主ボタン、/noah/purchases、/noah/sell。phone でも可。
- Wallet: 作者の価格から売上手数料（現行 10%。条件を満たしたら 0。`lib/sky-marketplace-policy.ts`）。決済の実費・税・返金は別表示。従量は次の段階（専用の端末（雲）の後）で、しきい値後払いの既存方針に乗せる。新しい課金型は作らない。
- hardware profile 依存: 全部。
- 失敗時: 支払いの結果不明は既存の再照合。確定の前に閉じた注文は、仮売上が期限で消える。接続の確認の失敗は理由を見せ、課金しない。
- 記録: 注文に、販売条件の revision、版 hash、系列、更新の条件、試用の回数、仮売上・確定・取消の各 ID と時刻。カードの情報は Stripe にだけ置く。

## 変える所

- 一覧: `/api/noah/launch` の公開一覧に、有料の公開版も出す（今は `pricing.model === 'free'` だけ）。
- 取り込んだ Agent（[noah-agent-intake.md](noah-agent-intake.md)）は、作者が引き取るまで無料のままにする。価格を付けられるのは引き取った本人だけ。
- 主ボタン: 接続計画の entitlement の段から決める。「接続」「試す（あと n 回）」「購入して接続（¥…）」。
- 販売条件に 2 項目を足す。`trialRuns`（0 以上。既定の候補 3）、`updates`（`family` / `this_version`）。既存の販売条件は `trialRuns=0`・`updates=this_version` として読む。
- 利用権の判定: `updates=family` の注文は、同じ作者・同じ識別名（`noah_instances` の family）の、審査済みで新しい版にも有効にする。返金・紛争・撤回は、今のまま全部の版に効く。
- 仮売上: Checkout を「後で確定する」形で作る。確定と取消は同じ注文 ID で冪等にする。**最初に Stripe の sandbox で、分配付きの後確定が今の destination charge で通るかを確かめる。** 通らない時は、支払い → 接続の確認 → 失敗なら自動で全額返金、の順へ切り替える。
- 2 回目からの 1 タップ: 本人の同意の上で、支払い方法を Stripe に保存する。Noah にカードの情報を置かない。
- 作者の受取先の登録は、価格を 1 円以上にした時だけ求める。無料で載せるなら不要。
- 試用は、コードを利用者へ渡さない場所（クラウド・提供者）でだけ使える。端末へ配る版の試用は、作者が明示して許した時だけ。

## 変えないもの

- 手数料率、最低価格（50 円）、JPY、返金と紛争の処理、test / live の分離。
- 支払い済みの判定を戻り URL でしない（既存の署名 Webhook と再照合）。
- カタログへの掲載や Passport を、提供者側のアクセス強制の代わりにしない（[sky-commerce-design.md](../sky-commerce-design.md) §11）。提供者サーバー型の有料 Agent は、利用権の受け渡しが入るまで売らない。

## 従量（次の段階）

1 回あたりの作者価格を、専用の端末（雲）の使用量の明細に足す。本人の月の上限で止める。作者への支払いは月次。まとめて請求して作者へ分ける形は、決済の形と制度の確認が要る（設計書 §10）。
