# 危険の早期発見（国・警察・学校向け。下書き）

2026-11-25 のノエルとかいやの会話（本人が貼った書き起こし）から起こした下書き。作るかどうかは本人の回答待ち。決まっていない所は「未決」と書く。コードより先に書く（[04](../structure/04-eve-noa-amc-sky.md) の 3 章）。

- 本人が言う一言: 「例えば銃とか作りようときに、こいつ銃作りようみたいな時にその個人情報と紐付けして、もしかしたら危険かもしれんねの犯罪予防になるかもしれん」
- Goal（Eveが作る）: 目的 = 学校などで、危険な物（銃・爆発物など。範囲は未決）を作ろうとする依頼に、事件の前に気づく。入力 = Noah・Eve に来た依頼の文と、その本人の登録情報。期待成果 = 人が確かめる候補の一覧と、法律に沿った連絡の記録。予算上限 = 未決。要る権限 = 登録の時の本人の個別の同意、運営の確認担当。
- Eveがつなぐもの: 新規Agent: 危険の分類（依頼の文から、種類と強さを出す）。確認の画面（審査者だけ）。連絡の記録。回線（eSIM）を流れる他社への通信は使わない（[03](../structure/03-esim.md) の 7 章）。
- AMCの工程: 1. 依頼を分類する（担当: 分類の Agent。合格: 試験の依頼で下の Jev の条件）。2. 強い物だけ、運営の確認担当（人）が見る（合格: 人が見る前に外へ出た件数 0）。3. 確かめた物だけ、決まった先へ連絡する（合格: 連絡ごとに下の「守る決まり 3」の根拠がある）。4. 全部の段を記録する。
- Jevの合格条件: 危険な依頼と危なくない依頼を混ぜた試験の束で、見逃しの率と、誤って拾う率が決めた値以下（値は未決）。人が確かめる前の外への連絡 0 件。同意の無い本人の依頼を対象にした件数 0。回線の通信を読んだ件数 0。
- 出力先: 運営の確認画面（審査者だけ）。本人には、規約と登録の画面で「何を見るか」を先に見せる。
- Wallet: 国・自治体・学校・警察との、施設や団体単位の契約（[05](../structure/05-business.md) の 1 章の 5・6）。値段は未決（先に「どのぐらいまで出せそうですか」と聞く）。利用者からは取らない。
- hardware profile 依存: phone でも可（依頼はどの端末からでも Noah・Eve に来る）。
- 失敗時: 誤りの疑いは人の確認に戻す。分からない物は外へ出さない。分類の Agent が止まった時は、拾わずに記録だけ残す（止まった事も記録）。
- 記録: 依頼の ID、分類の版、確認した人、連絡の根拠（照会の番号・令状の有無・緊急の理由）、時刻。依頼の文を保つ期間は未決。

## 守る決まり（作る前の条件）

1. **隠さない。** 会話の「その自分が何調べようかっていうセキュリティが外部から保護されるけど俺ら見れる」の両方を、登録の時に書く。「誰にも見られない」とは書かない。
2. **見るのは Noah・Eve への依頼だけ。** 回線の中身は、電気通信事業法の通信の秘密で見られない。守る物は中身だけでなく相手・時刻・回数も含み、他人に渡せるのは緊急避難・令状などの時だけ（総務省「[電気通信事業における個人情報等の保護に関するガイドライン](https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/d_guide_06.html)」の解説）。
3. **警察への連絡は法律の道で。** 本人の同意が無い第三者への提供は、個人情報保護法 27 条 1 項の例外の時だけ（1 号「法令に基づく場合」＝捜査関係事項照会など。[個人情報保護委員会の FAQ](https://www.ppc.go.jp/all_faq_index/faq1-q1-63)。2 号の、人の生命・身体の保護に必要で、同意を得るのが難しい時）。データそのものは売らない。売るのは、気づく仕組みと、人の確認の運用。
4. **答えない事を先に決める。** 依頼に答えて作り方を渡してしまうと、気づいても遅い。危ない作り方には答えない。会話の「無検閲」で何を許すかは、この決まりの中で決める（未決）。
5. **18 歳未満。** 学校の生徒が相手になるなら、保護者の同意などの扱いを先に決める。今の 300 人の試行の教育の相手は 18 歳以上（[trial-300](../noah/trial-300.md) の 2 章）。
6. **作る前に弁護士に確かめる。** 上の 2 と 3 は公的な案内を読んだだけで、この使い方での確認はしていない。

## 売り方（会話の案）

- 形で示す（「もう示すしかないけど、形で」）。予防ができる事を見せ、先方に予算を取ってもらう。
- 基本は海外（アメリカ）で考える。日本にも取ってほしい。「データは日本のもの」。
- 「アメリカに一旦これ話持って行ってます」と伝えると、日本の予算も取りやすい、という見立て。

## 決めていない事

- 作るかどうか。作るなら、誰に売るか（警察・自治体・学校・国のどこか。日本かアメリカか）。
- 何を危険とするか（銃・爆発物・ほか）と、確認担当は誰か。
- 依頼の文を保つ期間。
- 18 歳未満を相手にするか。
- 「無検閲」で何を許すか。
- 分類をどこに置くか。Jev は権限を持たない（AGENTS.md 7 章）ので、外への連絡は人が行う。
