# Noah — 保存時リファクタ担当Agent

- 本人が言う一言: 「VS Codeなどでファイルを保存した時」に、自動でリファクタした状態を保存したい。
- Goal: 本人が指定したコードと対応テストを対象に、保存イベントから公式Agentの修正・検証・書き戻しまでを実行し、Noahで運用開始/停止できる。
- Noaがつなぐもの: VS Code拡張の保存イベント、対象/検証条件、公式Agent接続、既存Work、隔離検証器、編集版。
- AMCの工程: 対象と運用状態確認→保存内容のsnapshot→元コードの検証→既存Workで修正依頼→出力と固定テストの隔離検証→運用状態/編集版の再確認→元内容を復元用に保存→修正を保存。
- Jevの合格条件: 公式Agentの実修正1件以上、型/テスト失敗時の書き戻し0件、本人の再編集への上書き0件、停止後の書き戻し0件、自己保存からの再起動0件、対象外/秘密ファイル取得0件、二重保存からの並列書き戻し0件。元ファイルへ復元できること。
- 出力先: VS Codeの対象ファイル、Noahの運用状態とWork結果。UIでは検証範囲を表示し、全プログラムの正しさは保証しない。
- Wallet: 既存ローカルモデルだけを使用。保存ごとの同時実行1件、入力/時間/回数を制限し、有料APIへ切り替えない。
- hardware profile依存: このMacのVS CodeとNoah hostが起動中に動く。端末はcache、Workは既存account正本。Macを閉じた間の運用、スマホのファイル監視は別工程。
- 失敗時: 元ファイルを維持し、失敗理由を表示。入力版が変わった出力を自動適用しない。終了不明を自動再送しない。
- 記録: Agent/版、Work ID、入力と出力のhash、検証条件と結果、対象ファイルの版、適用/停止/競合。認証・Git履歴・環境変数は入力へ混ぜない。

## 最初の実装境界

VS Code拡張から選択したJavaScript/TypeScriptファイルと固定テストだけを渡す。対象/テスト/担当Agentの変更時は運用を止め、Noahで再開する。編集領域の全体読取や任意shellをNoahへ渡す方式にしない。Agentは隔離作業領域内で候補ファイルを作る。テストは候補と元コードに同じ条件で実行する。型/構文/指定テストが通っても、未試験の挙動や設計全体の正しさは未確認。

イベントは保存→待機→実行→検証→保存/変更なし/競合/失敗。処理中の新しい保存は最新1件にまとめ、先の出力は失効させる。本人の未保存編集も上書きしない。自己保存の抑止はファイル名だけでなく期待hashを照合する。

Git commit/push、PR作成、外部送信はこのAgentの操作に含まない。Noahへの接続と自動運用の有効化を区別する。実装と実保存の受入が済むまで「保存時に稼働中」と表示しない。

## 2026-11-16 実装と受入

公式Aider 0.86.2・既存qwen3:4bを担当にし、VS Code拡張0.1.0をローカル導入した。Noahの`/noah/code`で対象と固定テストを表示し、運用開始/停止する。対象は1ワークスペース1コード＋1テスト、各16KiB・Agent prompt12KB以内。外部依存なし、TSはstrict型検査、JSは構文と固定Nodeテスト。型検査器は供給されたソースと自身の標準ライブラリだけを読み、プロジェクト設定やpluginをロードしない。テストはdigest固定Node 24 containerで実行し、外部network/host mountなし、実行20秒・host待機30秒で止める。

`/__noah/save-refactor`のGET/POSTで本人別の対象登録、`/:id/start|stop|heartbeat`で運用状態、`/:id/validate`で固定snapshotの検証、`/:id/execute`で既存Workを発行する。loopback Host/Origin・owner照合を必須とし、世代ID変更で古い処理を失効させる。heartbeatは5秒、20秒届かない状態では実行/検証を拒否する。検証はhost全体で同時1件。HTTP切断時も検証containerを停止する。停止中から自動再開しない。

実保存で `for` ループのsumが`reduce`へ整理され、指定テストを通して同じファイルへ保存された（Work `242b9cdb-3e2d-45d5-8f39-3301755aebe0`）。Noah停止後の保存で新規Work 0件、自己保存による再起動0件、復元コマンドで元コードへ戻ることを確認。別のAPI通し試験で壊れた候補を拒否し、正常候補だけが通ることを確認した（Work `3add26b5-77ff-4337-93fd-2992364328f5`）。合成コードの範囲の合格で、プロジェクト全体や未試験の挙動の保証ではない。

復元前データはVS Codeのworkspace extension storageへWork別に最大100件保存する。対象は画面に開いた保存済みファイルだけ。Mac/Noah/VS Codeの稼働が必要で、Noah再起動後は拡張の接続コマンドをやり直す。クラウドからの編集、全repo解析、複数ファイル、外部依存テストは未対応。導入手順は`toolkits/noah-vscode/README.md`、証拠はSSDの`work/verification/noah-save-refactor-20261116/`。
