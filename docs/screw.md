# Screw — NoelleのGrapheneOS導入への入口

![ScrewからGrapheneOS導入へ進むためのアニメーション](assets/cover-screw.gif)

**Screw**は、RockのリポジトリからNoelleの**PRIVATE/PIXEL**へ進むための案内名です。GrapheneOS導入システムの提供元はNoelleです。

## 導入へ進む

1. [NoelleのGrapheneOS導入ページ](https://privatepixel.uk/grapheneos-install)を開く。
2. [Noelleの導入ガイド](https://privatepixel.uk/guide)で対象端末、準備、手順、サポート条件を確認する。
3. 端末の対応状況とバックアップを本人が確かめてから、提供元の案内に従う。

Rockの[Screw紹介](../README.md#screw--grapheneos導入の入口)は外部サービスへの入口です。PRIVATE/PIXELのソース、インストーラー、OSイメージはRockに取り込んでいません。GrapheneOS公式プロジェクトとも別です。RockstarOSの導入方法を探す場合は[Developer Previewガイド](preview-installation-ja.md)を参照してください。

## 提供元と現在地

| 項目 | 内容 |
| --- | --- |
| 案内名 | Screw |
| 導入システムの提供元 | Noelle / PRIVATE/PIXEL |
| Rockの担当 | リポジトリ内の紹介と公開ページへのリンク |
| 動作確認 | 上記2つの公開ページへのアクセスを確認。Rockからの実機インストール試験は未実施 |

Noelleのリポジトリは非公開で、ライセンスはソース等の再配布を許可していません。利用許諾を得るまではScrewを独自インストーラーやコードの複製として扱いません。
