# avocadoMini — 工場の設計開発部門への依頼書

目的は、同一の携行本体にR5最低機能を収められるかを**証拠で判断し、成立する場合に製造用データを作ること**。本依頼書と[設計入力](README.md)はRFQ/共同開発の説明に使える。現在のR0を製造指示、発注、量産承認と扱わない。初回試験地域は米国。OWNERが別途決める実試験地点、契約、支払/調達、住まいへの施工・実機利用はこの資料だけで許可しない。

## 依頼する順序と各段階の引渡し

**E0 実現性・寸法証明。** 受託先は、実際に供給可能な衛星IP radio/antenna、地上音声、Wi-Fi、SoC、sensor、電池pack、低出力空間表示と指入力、充電/安全部品を正式資料の版・質量・供給状態と共に提示する。Stow/Ready/Carry/空dockの同一原点3D CAD、干渉/公差/組立/修理断面を提出。`194+g+δ+e≤200mm`を全途中姿勢で判定し、光路・antenna/ground/手・放熱の空間を同一図面で示す。**不成立ならその時点で停止**し、根拠と要求変更の選択肢だけを返す。D76、450gは研究仮値だが200mmの全状態と一台自律は利用者要求として保つ。

**E1 機能別bench。** 出力を安全側で制限した光学/指入力、米国向け衛星radio→Mini自身のIP→Wi-Fi client、市販clientのDNS/TLS、番号付き実着信と双方音声、電池pack/昇圧/RF peak、AON wake/機構停止を個別に測る。衛星網はMini完成機型式・antennaと結びつく米国provider書面で双方向IP、第三者clientへの共有権、料金/停止、voice/番号と供給・認証経路を確認する。messageだけ、proxy専用packetだけ、他端末の契約だけならOI04は不合格。光学方式が安全・可視・距離・視野を満たさなければ空中着信は不合格。bench合格を閉箱合格へ転記しない。

**E2 EVT回路・機構。** E0/E1を通した一構成に限り、正式schematic、全pin表、netlist/ERC、BOM/代替/lead time、PCB stackup/配線・GerberまたはODB++、製造/実装図、RF/antenna資料、pack保護/充電、熱解析、光学/安全interlock、FW buildと較正・復旧手順を提出。基板と機構の版を結び、同じ閉箱でOI01〜07、MP01〜06、MG01〜07の対象試験を実施する。実機・通信契約・光学測定・安全評価の記録がない項目は未合格のまま。

**E3 製造リリース判定。** EVTの不具合改訂、必要な安全/EMC/RF/電池/光学/米国完成機評価、工程FMEA、製造検査治具、100%出荷検査、追跡番号、電池交換/修理/回収、署名・更新・復旧、供給/価格と保証条件を同じ部品/基板/OS版で揃えてから、OWNERと責任者が製造版を承認する。E0/E1/E2の資料を束ねただけではE3へ進めない。

## 見積回答に要求する内訳

- E0、E1、E2、E3を別見積とし、工学工数、部品・試作・治具、RF/光安全・電池/EMC試験、米国のProvider/認証、量産準備を分ける。契約前の価格や日数をこの資料で捏造しない。
- どの会社がradio/antenna reference designの権利、網利用条件、完成機認証、電池packの設計/輸送、光安全、建築施工の責任を持つか明記する。供給/知財/輸出制限と代替不能な部品を示す。
- 各gateの不成立時に渡す測定値と資料、データの所有/再利用、第三者への非開示、追加費用、変更承認方法を明記する。
- 工場が200mm、一台衛星→Wi-Fi、空中着信、携行電池のどれかを緩める提案をする場合、元要求との差、得る能力、失う体験、寸法/電力/費用を同じ尺度で返す。OWNER承認までは原設計を置換しない。

## この時点の停止判定

既製PLANET 9523基板は幅75mmで仮内径72mmを超え、既製9770は140×60×16mm・185gで光学/電池との共存CADなし。仮2-cell packはcell以外の軸余白5mm、仮24h/AP2hでは全待受負荷へ0.804Wしか残らない。既存の四分割光学案も採用済み部品ではない。従って**今すぐ製造工場へPCB/筐体の加工発注は不可**。E0/E1の専門設計・測定を依頼する資料として渡す。
