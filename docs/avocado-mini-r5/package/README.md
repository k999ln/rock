# avocadoMini RockstarOS 統合設計仕様書 R5

2026年9月24日。ゲームを中心に、制作・学習・限定した生活支援へ展開するための統合基本設計。

## 読む資料

- `avocadoMini_RockstarOS_R5_Integrated_Design.pdf`：51ページ。図面、部品候補、計算、OS、起動・操作、組立・受入計画を統合した閲覧用設計書。
- `avocadoMini_RockstarOS_R5_Integrated_Design.docx`：同内容の編集用Word。
- `integrated_design.md`：見出しと表を検索できる本文。
- `drawings/`：設計検討図8点のSVGとPNG。拡大可能な原図を含む。
- `calculation_results.json`、`verify_calculations.py`：仮定付きの計算結果と14件の算術チェック。
- `references/`、`reference_index.json`：生活・操作・接続・表示の研究32項目と追加資料。
- `package_manifest.json`：同梱ファイルのサイズと照合用SHA-256。設計の製造承認を示す証明書ではない。

## この版の状態

使用時全高200mm以内、1本で自律、別Edge Hubを必須にしない、同型miniの増設、裸眼で周囲空間に粒子が分布する目標を維持する。

**製造承認は保留。** 表示エンジン、単体の精密3D入力、最終収納、電源・熱、専用NPU、確定回路と加工図は未決を含む。候補部品の型番や論理APIが存在しても、完成品の実装・性能・安全を証明したものではない。実機試験0件。

原図は製造CAD、回路図、基板製造データの代用品ではない。本資料だけで加工、通電、光源実験、量産へ進めない。製造までに必要な成果物と審査条件は本文の「製造承認に必要な成果物」「未確定事項」にまとめた。

R5はR4要求と2026年9月24日の研究を統合した版で、古い固定親機・別Hub構成を復活させない。この作業ではGitHubや外部サービスを変更していない。

## 計算の再確認

Python 3で `python3 verify_calculations.py` を実行する。標準ライブラリーのみを使用し、同じフォルダーの計算結果を再生成する。チェック成功は数式・条件の再現であり、ハードウェアの受入合格ではない。
