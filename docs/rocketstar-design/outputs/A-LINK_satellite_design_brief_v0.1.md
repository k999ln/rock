# A-LINK 衛星単体のデザイン検討書

2026-09-21 / v0.1 / 外形・配置の比較案

## いま決まっていること

目的は、小型通信衛星を両段再使用ロケットで運び、avocadoMiniへ衛星通信でデータを届けること。現行の統合基本設計には、衛星の質量・電力配分、通信系統、軌道、端末接続、試験計画を記載している。

衛星の外観、具体寸法、アンテナ方式、太陽電池の展開形状、内部配置は未選定。本書はそれらを決めるための比較案であり、製造図や収納・通信性能の証明ではない。

現行の比較条件は、衛星1機500kg、定常電力1kW、高度550km、初回2機。いずれも設計の仮予算。3案がこの枠へ収まることを確認したものではない。

## A 箱型＋左右の太陽電池

金色の断熱材を持つ箱型本体に、左右の発電パネルと地球側の通信アンテナを配置する。王道の衛星らしい外観。機器配置を詰める作業基準の候補とする。

画像の小型反射鏡と平面アンテナは配置比較の例。両方を必ず搭載する決定ではない。実際のアンテナを選び、放熱面、太陽電池、推進系と干渉しないよう調整する。

## B 薄型＋平面アンテナ

平たい本体の地球側へ広い通信面を置き、発電パネルを左右に展開する。すっきりした輪郭を選びたい場合の候補。

薄さは内部機器・配線・構造・熱輸送・収納時の重なりと一緒に決める。平たい外観を採用しただけで電子走査アンテナや高速通信が成立するわけではない。

## C 大型の展開アンテナ

小型の本体から反射鏡を広げ、通信アンテナを外観の主役にする。avokado方向への利得を高める方式を検討する場合の候補。

高利得化では向きの制御やビーム範囲が重要になる。展開の信頼性、形状保持、太陽電池との干渉、収納寸法を検証する。画像の直径や比率は確定寸法ではない。

## 外観を選んだ後に固定する内容

1. avokadoへ届ける情報：文字・通知、音声、動画などの必要速度と頻度。
2. 受信環境：屋外、窓際、室内。端末内蔵か屋外アンテナを用いるか。
3. 収納状態の三面図と、ロケット側の収納包絡。
4. 展開後の三面図と、アンテナ・太陽電池・放熱面の向き。
5. 内部配置、機器別質量、電力、熱、重心、ハーネス。
6. 展開・振動・熱真空・電波・干渉の試験条件。

見た目の作業基準としてAを置けるが、A/B/Cの選択は未確定。金色の断熱材、発電面、放熱面、通信面にはそれぞれ機能があるため、色と形の変更はその機能と両立させる。

## 参照

- [NASA — Communications](https://www.nasa.gov/smallsat-institute/sst-soa/soa-communications/)：通信量・質量・電力の比較検討、高利得化と指向の関係。
- [ESA — Biomass: The satellite](https://www.esa.int/Applications/Observing_the_Earth/FutureEO/Biomass/The_satellite)：大型展開反射鏡と衛星の配置・安定性の検討例。Biomassの仕様を本衛星へ流用するものではない。

## 画像の位置付けと生成条件

内蔵画像生成ツールで作成した外観コンセプト。CAD、メーカー図面、実機写真ではない。透視表現・部品形状・干渉・展開機構は工学的に検証していない。寸法の縮尺を表していない。

生成プロンプトの要旨：民生小型通信衛星の形状選定用に、A＝箱型本体＋左右の太陽電池＋別体通信面、B＝薄型本体＋広い平面通信面＋左右の太陽電池、C＝本体＋展開メッシュ反射鏡＋独立した太陽電池を、一枚の中立背景の比較ボードとして描く。500kg級の検討であり寸法・性能を断定せず、発電面と通信面を区別する。ラベルはA/B/C、CONCEPT STUDY — NOT TO SCALE。惑星、電波の発光表現、ロゴ、性能保証値を入れない。
