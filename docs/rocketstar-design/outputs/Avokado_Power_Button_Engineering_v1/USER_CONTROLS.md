# avokado 電源ボタン

| 操作 | 使用中の動作 |
| --- | --- |
| 1回押す | 待機へ。もう1回で画面を復帰 |
| 2回押す | ホームへ。ロック中はロック画面 |
| 3秒以上押して離す | 保存して正常に電源OFFを要求 |
| 10秒押し続ける | フリーズ時の強制電源OFFを要求 |

電源OFF中は、最初の1回で起動。起動のために押したボタンを保持しても、そのまま強制OFFにはしない。

待機中もOSと許可された通信・バックグラウンド処理は動く。復帰してもカメラとマイクは自動的にONにしない。

2回押しは最初の解放から350ms未満で次を押す。単押しの動作は2回目の待ち時間後に確定する。

10秒は強制OFF要求の閾値。遮断回路の実装とOFF完了時間は実基板で確認する。今回確認した32件はソフト模型の試験。
