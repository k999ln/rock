## 設計資料への適用

C1統合設計書の第02章にある外観・色・仕上がりの方針は、このC2画像と変更表を最新の意匠基準とする。C1は履歴として保持する。無人2段、両段再使用、上段の風上熱防護、機体に残る衛星収納扉という構成は継続する。

銀色は見た目の指定であり、実際の合金や耐熱処理の選定ではない。黒い面の3点はavokadoから移した意匠モチーフで、ロケットにカメラ3台を追加する仕様ではない。細いシアンも意匠表現であり、発光装置の搭載を決めたものではない。熱防護面は暗色のまま残す。C2は形状・材料の製造承認や性能計算の改訂を行わない。

画像右下のavokadoはデザイン上の共通性を示す比較用の小図で、機体と同じ縮尺ではない。画像の細部は機構CADの代わりにしない。
