# RETURN-1 搭載衛星・avokado 接続条件

改訂：2026-09-23 / 対象：ロケット上段―A-LINK 衛星―地上通信網―avocadoMini Tower20 E3

本書は搭載品の接続条件を整理するための設計原稿である。要求・作業基準・未解決条件を区別し、未決定の数値は未記入のまま管理する。実部品 CAD、収納包絡、分離系の承認、機械・電気・熱・無線の実証は未完了。製造・飛行承認を示す文書ではない。

## 1. 構成と質量の境界

RETURN-1 は通信衛星を軌道へ放出し、両段を帰還・再使用する。衛星は軌道上で運用する搭載品であり、地上の avokado 本体を打ち上げる計画ではない。衛星の放出後、上段側のアダプター・保持物は上段に残す。機体扉は保持し、帰還時に閉鎖できることを要求する。

| 項目 | 設計上の扱い | 確定のために必要な証拠 |
| --- | --- | --- |
| 輸送対象 | 通信衛星 2 機、合計 1,000 kg を要求案とする | 各衛星の実部品積上げ、重心・慣性、搭載配置、上昇・帰還性能との整合 |
| 各衛星の 500 kg | 放出時の衛星全体。衛星側の分離部、展開物、搭載推進剤、成長余裕を含む仮配分 | 計量可能な質量台帳。余裕は実部品と分けて記録する |
| 上段側の分離・保持部 | 上段の乾燥質量に計上。衛星側と重複計上しない | 部品ごとの帰属、放出前後の質量台帳 |
| B-H1 外形 | C1 の D07 により、地球側の平面通信面・側方の太陽電池・宇宙側の放熱面を以後の作業用配置に選定 | 寸法・質量・面積・通信性能は未確定。アンテナ設計、発電・放熱・姿勢・収納・展開の統合評価が必要 |
| 衛星の 1 kW | 1 機あたりの定常電力比較点。発電能力、常時 RF 出力、実測消費電力ではない | 食・劣化・ピーク・再充電・放熱を含む電力計算と実機試験 |
| 軌道・初期配備 | 旧設計の高度 550 km・傾斜角 53 度・2 機は検討条件 | 発射場、対象地域、待ち時間、地上局との可視条件を含む配置解析 |
| 利用者端末 | C1 の D08 により、**使用時 200 mm の Motion Tower 4 本＋別体 Edge Hub**と 9704 の別筐体実証を選定 | 最新 E3 図書を基準に機構・電源・通信を再統合する。実機受入・製造承認ではない |

合計 1,000 kg はロケットの実績能力ではなく、衛星 2 機の収納成立も示さない。異なる軌道面への投入能力、初期 2 機での全球常時サービス、室内の直接衛星受信は成立済みとしない。B-H1 の通信面積や衛星電力が増える場合は、搭載質量・包絡とロケット性能へ変更を戻す。

### 1.1 自前衛星網と端末実証の区別

| 系統 | 通信経路 | 検証できる対象 |
| --- | --- | --- |
| 自前 A-LINK 網 | 適合する端末無線機―自前衛星―地上ゲートウェイ／コア網―配信サービス | 自前衛星の通信方式、フィーダーリンク、対象地域・時間・容量。これから開発する系統 |
| 初回の端末実証 | E3 Hub または試験 PC―有線接続―別筐体 RockBLOCK 9704―Iridium IMT―Cloudloop | 通知等の受信・認証・保存・ACK・再配信。自前衛星や RETURN-1 の性能は検証しない |
| 地上経路 | E3 Hub―許可済み Wi-Fi／契約済み携帯―配信サービス | 自動切替、到達性、接続回復、地上経路で扱えるデータの配信 |

RockBLOCK 9704 は自前衛星に接続する NTN モデムとして採用しない。自前網の端末モデム、周波数、波形、認証網、地上局は別途整合させる。透明中継を使う案では端末と地上ゲートウェイの同時可視を検討し、衛星内の蓄積中継・衛星間リンクを備えるとは仮定しない。

「電源投入後に使える回線へ自動接続する」を端末の方針とする。全経路が遮断・未契約・到達不能のときは受信待ちを表示する。電源投入だけで地下・金属遮蔽内を含む全場所へ常時届く、という保証にはしない。

### 1.2 E3 側の接続先

通信制御とメッセージ保存は Edge Hub に置く。4 本のタワーへ個別の衛星モデムを載せない。E3 の Hub 外形 240×200×70 mm は提案寸法であり、通信機器の内蔵空間が確保済みとはしない。E3 の電力枠は Hub 100 W＋4 塔×4 W＝DC 116 W という計算用配分。衛星・携帯・Wi-Fi の追加消費がこの枠へすべて含まれるとは扱わず、給電元ごとに再集計する。[L1][L2]

初回の 9704 実証は別筐体の衛星ポッドを使う。メーカーは同じ筐体への他送信機の共置を認めておらず、指定アンテナには空の見通し・上向き・地面またはグラウンド面となる金属から 1 m 以上という設置条件がある。これは 20 cm タワーの高さ指定とは別の設置条件である。[S1][S2]

### 2.1 接続条件の変更管理

設計の各数値には単位、座標系、動作状態、許容範囲、出典、測定／推定の別、改訂を付ける。衛星寸法、質量、分離機構、上段扉、アンテナ、バッテリー、給電方式の変更は、影響する ICD と解析・試験を再レビューする。既存の一般ロケットガイドに載る荷重値を RETURN-1 の保証環境として転用しない。

衛星通信と管制は利用者サービスの機能を分ける。avokado は通知等を受ける端末であり、ロケットの飛行制御・分離許可・推進操作の権限を与えない。

## 3. 地上検証と外観図の承認範囲

### 3.1 試験の成立条件

試験開始前に対象機の構成版、要求値、試験条件、計測器、校正、有効なモデル、異常時停止、データ保存先を決める。認定試験・個体受入試験・開発比較を区別し、合否値を結果を見てから変更しない。以下は未実施の試験計画であり、購入・契約・電波送信を実施した記録ではない。NASA GEVS は環境検証方法の参考であり、本計画へ自動適用される認証ではない。試験条件は本機の実環境へ合わせて決定する。[S3]

| ID／対象 | 試験前にそろえるもの | 完了を判断する証拠 |
| --- | --- | --- |
| P-G01 収納・保持・分離 | 承認 CAD、実機相当の扉・分離部、代表質量・重心・慣性、吊具影響の補正、計測計画 | 2 機と扉・配線・機体の非接触を確認。解除だけでなく再接触回避・状態確認・扉閉鎖まで検証 |
| P-G02 機械・熱・電気環境 | 結合荷重と環境仕様、試験体の対応、治具・境界条件、事前機能記録 | 振動・音響・分離衝撃・熱真空・EMC 等の必要な試験後に、構造と機能が承認された許容内。条件未決定では合格を出さない |
| P-G03 統合状態と故障 | 実ハーネスまたはその忠実な模擬、電源過渡、分離信号、ソフト版、故障注入表 | 接続喪失、誤信号、低電圧、片方未分離でも意図しない分離・展開・送信をしない。残留状態と帰還判断を区別できる |
| P-G04 自前衛星通信 | 実方式・帯域、端末／衛星／ゲートウェイの互換構成、伝搬・ドップラー条件、校正済み RF 接続 | 認証からアプリ保存まで両方向を確認。利用者リンク単独でなく中継を含む通信余裕・容量・遅延を記録。地上 RF 試験を軌道実証と呼ばない |
| P-G05 既存網端末実証 | 9704 の版、別筐体、メーカー適合アンテナ／配線、見通し、USB 給電、契約、試験先とデータ | 地上アプリ経路を切った条件で衛星受信ログと保存・アプリ ACK を対応付ける。Iridium の成功を自前網の成功に転記しない |
| P-G06 E3 同時動作・復旧 | Hub と 4 塔の実構成、音声・ゲーム負荷、通信給電元、USB 構成、保存媒体、費用設定 | 閉箱で受信中の温度・帯域・電源・音声／映像への影響を測る。電源断・ACK 消失・経路切替後の重複抑止と復旧を確認 |

9704 の USB 実証では、500 mA を供給できる直接のホストポートと起動後の USB 列挙を確認する。共有電源・USB 帯域は E3 の 4 カメラと音声を含めて検証する。メーカー条件に合う接続を使い、長距離の屋外配線、耐候、接地、必要な保護は別の設置設計とする。[S4]

試験結果は「文書確認」「ソフト模擬」「地上実機」「軌道実証」に分けて保存する。E3 の計算再現件数や受信ソフトの模擬試験件数を、機体・衛星・電波の実機合格件数へ加算しない。
