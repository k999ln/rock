# A-LINK 衛星網・段階展開の設計入力

2026-09-21。計算は球形地球・円軌道の一次近似。ユーザーの「電源がつけばどこでも受信」を製品目標として記録し、衛星・携帯・許可済みWi-Fiの自動選択を採用する。対象地域が未指定なので、拡張案は極域を含む全球を検討対象に置く。屋内、地下、遮蔽、回線契約、容量を含む無条件の受信保証ではない。

## 1. カバー範囲の再計算

地球半径 R=6,371 km、高度 h=550 km、最低仰角 e=25°。地球中心から見た可視円の半角は ψ=acos[R cos(e)/(R+h)]−e。可視円の地表半径は Rψ、面積比は f=(1−cosψ)/2。

| 計算項目 | 結果 |
|---|---:|
| 可視円の半角 ψ | 8.4585° |
| 地表半径 Rψ | 940.55 km |
| 最低仰角での斜距離 | 1,123.28 km |
| 1機の理想可視面積 | 約277.4万 km² |
| 全球面積に対する割合 | 0.54387% |
| 全球面積÷1機可視面積の切上げ | 184機 |
| 550 km円軌道の周期 | 約95.50分 |

184機は面積の合計だけから求めた**必要条件の下限**。円の隙間、重複、移動、故障、保守、端末へのビーム割当を無視しており、必要十分な衛星数ではない。またこの円は「地平線より25°以上に衛星が見える幾何範囲」であり、同時に全面へ送信できる通信容量を意味しない。2機の瞬間可視面積は、重ならなくても全球の約1.09%以下。

高度と最低仰角を同じにすると、53°傾斜軌道で到達できる緯度は理想上±(53+8.4585)=±61.46°まで。極域を含む全球向けの最終配置には使えない。低軌道衛星による連続通信には複数機の連携が必要で、極軌道は時間とともに全球を通過できる。ただし全球通過と常時接続は別条件である。[ESA — Types of orbits](https://www.esa.int/Enabling_Support/Space_Transportation/Types_of_orbits)

## 2. 実証から拡張まで

**段階0：地上で端末と自動選択を実証。** 実機アンテナ、筐体・人体損失、衛星相当の周波数ずれと通信断を試験する。短い通知の受信から始め、実測した感度・消費電力・熱を衛星設計へ戻す。携帯/Wi-Fiで利用できる機能と、衛星直通で成功した機能を記録上も表示上も区別する。

**段階1：550 km・53°・2機の軌道上実証。** 既存の初回打上げ案を実証用途として維持する。2機は同一軌道面で安全に分離し、位相差は衝突回避と試験時間帯から設定する。日本等の試験点で、可視通過中の通知受信、周波数追従、屋外受信、地上回線への切替を検証。専用地上局と予備手段を用意し、地上局も同時可視でない時間は衛星に保存した署名済み配信データを使用する。衛星間通信は初期実証の必須条件にしない。即時配信、常時接続はこの段階では約束しない。

**段階2：地域・容量を測る拡張実証。** 6〜12機程度を複数軌道面に追加する案を、地域別の待ち時間と費用を比較するための候補とする。既存の携帯/Wi-Fiを運用上の主な補完手段に据える。最終候補の近極軌道も先行して試験し、53°だけに投資を固定しない。この機数で常時接続が成立するという意味ではない。

**段階3：全球用の軌道配置を比較。** 高度550 km、傾斜角87〜90°の近極軌道を中心に、12軌道面×24機=288機、18軌道面×24機=432機、24軌道面×24機=576機を比較候補とする。軌道面の間隔、各面内の位置、隣接面間の位相は最適化前。面積下限に倍率を掛けて合格と判断しない。赤道付近の隙間、極域での集中、衛星1機/1面の停止、混雑地域、地上局の可視、引継ぎ時の2機可視を評価し、足りなければ数・高度・傾斜角を再変更する。

## 2A. 実行した粗い幾何シミュレーション

全球のFibonacci球面点2,048点、24時間を300秒間隔で288時刻評価した。高度550 km、最低仰角25°、傾斜角87°、円軌道。P軌道面、各面24機とし、昇交点赤経 Ω_j=πj/P、位相 u_j,s(t)=nt+2π(s/24+j/(24P)) と定義。j=0〜P−1、s=0〜23。この本書独自の仮配置を標準Walker配置とは称さない。地球自転7.2921159×10⁻⁵ rad/sを反映し、地表方向と衛星方向の内積≥cosψなら幾何的可視と数えた。

| 仮配置 | 全点・全時刻平均の可視率 | 最悪地点のサンプル可視率 | 全点可視だった時刻 | 最小可視衛星数 | 最長の連続未可視サンプル |
|---|---:|---:|---:|---:|---:|
| 12面×24機=288機 | 96.0459% | 89.2361% | 0 / 288 | 0 | 3点×300秒=900秒目安 |
| 18面×24機=432機 | 99.9754% | 99.3056% | 194 / 288 | 0 | 1点×300秒=300秒目安 |
| 24面×24機=576機 | 99.99915% | 99.6528% | 283 / 288 | 0 | 1点×300秒=300秒目安 |

**3案すべてに未可視サンプルがあった。** この配置では576機でも全球常時可視を満たしたとはいえず、追加前に軌道面境界・位相を見直す。平均可視率は面積・時間を平均した幾何指標で、利用者ごとの接続率や通信品質ではない。未可視サンプル数×300秒は粗い指標で、正確な通信断時間ではない。時刻・地点の間にある隙間を見落とせるため、仮に100%でも常時接続の証明にはならない。24時間の両端はつなげず集計した。通信収支、建物・地形、容量、地上局、軌道摂動、故障は未評価。

再現ファイル：`work/autolink/coverage_screen.py`、`work/autolink/coverage_screen_results.json`。可視円端の位置から独立に局所仰角を求め、25°へ戻ることも確認した。

## 3. 打上げ・衛星設計への影響

既存ロケット設計は機体側分離アダプタを上段乾燥質量18 tに計上し、衛星側接口と搭載推進剤を各機500 kgに含めている。近極軌道での1 tの実運搬能力、実収納、衛星の質量増への余裕は未検証で、帰還条件とともに再計算対象。2機/便を同一軌道面へ投入できると仮定した最低便数は、288機で144便、432機で216便、576機で288便。補充・予備・打上げ損失を含まないので、量産展開は大型機への相乗りや多数機同時搭載との費用比較が必要。初回2機用ロケットの成立は全球網の展開能力を証明しない。

地球向き平面アンテナ、太陽電池、放熱面を分けたB系配置を作業基準とする。通信速度・必要利得・走査端の損失・送信ビーム数を測るまで開口と送信電力は未確定。衛星の定常1 kWは旧版の全機電力仮予算であり、RF出力1 kWではない。[NASA — Small Spacecraft Communications](https://www.nasa.gov/smallsat-institute/sst-soa/soa-communications/)
