# Sky実行パスポート — 2026-09-12

Skyの商品を開いた利用者が、開発者に聞かなくても「どこで動くか、誰のsystemへ接続するか」を判断できる共通契約を追加した。

## 表示する項目

- 主な実行場所と対応実行場所
- 実行先の管理者
- 接続方式と現在利用できる経路
- Cloud依存とCodexの役割
- データ保存先
- オフライン可否と無人継続
- 必要な処理能力
- RockstarOS端末単独運転と自家発電確認の区別

ToB掲載フォームはこの申告を`runtimeProfile`として保存する。審査済みOSサービスは固定カタログの`execution_profile`へ移し、OS管理層が未知の値や条件差分を拒否する。ToCの商品画面は`EXECUTION PASSPORT`として宣言値と現在のPC接続能力を表示する。

## サブスク顧問の経路

主経路は`Sky → RockstarOS端末 → OS管理MCP → サブスク顧問`。CloudとCodexは必須ではなく、データは端末内に置く。実機前のWeb開発版では`Sky → このPCのOS管理MCP → サブスク顧問`をフォールバックとして表示する。

端末だけで計算・保存・継続できる契約は実装したが、自家発電は未実装・未検証である。電源が端末バッテリーか外部電源か、発電入力があるかはツール開発者ではなく、将来のRockstarOS Energy serviceが観測して表示する。
