## 3. 名前の法的リスク（重要）

- **「MII」は Nintendo of America の登録商標**（US Reg. No. 3451478, Class 9: ソフトウェア、ゲーム関連。2008 登録、2018 更新、有効）。
- 物理端末＋ゲーム用途で `mii` を使うと、同一クラスで混同のおそれがある。日本でも任天堂は「Mii」を商標登録している。
- 選択肢: (a) 商標弁理士に類否を見てもらう、(b) 表記を変えて区別性を出す（例: `mii.` のピリオド付き、`avokado mii` のように常にブランドを前置）、(c) 別名を今のうちに決める。
- **今回のリポ内では `mii` を使う**（本人指示）。ただし対外公開（PDF 配布、サイト、CM）前に (a) を済ませる。task 05 に 1 行入れた。

## 4. 良い点（残す）

- 「置く」ではなく「埋め込む」。製品ではなく建築の仕様に入る、という位置づけは、Apple が家電でなく「生活の前提」になったのと同じ戦略で、mii に最も合う。
- 白い建築に黒いセンサー帯、という意匠は一貫していて強い。Column / Puck / Slot の 3 形態も、中身が同じなら「同じ家族」として美しい。
- 文字が少ないのは正しい。構造図を 2 枚足せば完成する。
