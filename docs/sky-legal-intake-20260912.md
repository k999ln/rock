# Sky 日本語法律相談受付 — 実装と安全境界

更新日: 2026-09-12

## 目的

SkyのAgent Hubへ「法務受付」をready商品として追加した。Timelineの法務受付投稿、役割ボタン、または「何をしてほしい？」への自然文から担当を開ける。利用者が最初に安全・期限・相談分野・地域・現在の段階を整理し、政府・裁判所の公式情報だけを検索する法令AIと無料窓口で解決を試す。本当に弁護士相談が必要な場合だけ引継ぎ要約と日本語対応候補を表示し、刑事弁護案件は藤原茜弁護士を第一連絡候補にする。

## 実装範囲

- 差し迫った危険、逮捕・拘束、家庭内暴力、公的書類、7日以内の期日を先に確認する。
- 一般情報、弁護士相談推奨、至急、緊急の4段階へ決定的なルールで分類する。
- 相談分野ごとに次の行動と用意する資料を表示する。
- OpenAI Responses APIのWeb検索を使い、許可した政府・裁判所ドメインだけから一般情報を生成する。回答にはクリックできる根拠リンクが1件以上必要で、根拠がない回答は画面へ出さない。
- NY CourtHelp、LawHelpNY、州裁判所セルフヘルプなど、無料または公的な解決窓口を先に表示する。
- 弁護士相談が必要な場合だけ、本人入力を整理した引継ぎ要約と最大5件の候補を表示する。
- 刑事弁護案件では藤原茜弁護士を第一連絡候補として明示する。これは自動振分け・受任確定・推薦ではない。
- 連絡操作はメール作成、電話、公式サイトを開くところまで。送信・発信・予約・契約は本人が行う。
- 入力画面を「安全確認」「相談内容」「回答・引継ぎ」の3ステップに分け、一度に必要な項目だけを表示する。
- 法務受付との会話として、案内、利用者の相談、判定、公式情報に基づくAI回答を同じスレッドへ表示する。
- 法務・特許の会話画面はデスクトップで幅980px、スマートフォンでは画面下から開く全面シートにし、開いた直後は担当名と説明から読めるよう自動スクロールを抑える。
- 各ステップに進捗、戻る、相談内容の修正を設ける。スマートフォンでは主要ボタンを横幅いっぱい・48px以上にする。
- 弁護士候補は第一連絡候補または上位2件だけを先に表示し、残りは「ほかの候補」に折りたたむ。
- Agent Hub統合後にローカル応答、型・lint、法律相談11件、全124件、production build、API 143項目を確認した。公開環境での操作確認は再配信後に行う。

## データとプライバシー

候補データは、利用者から提供された在ニューヨーク日本国総領事館の「日本語の通じる弁護士リスト」（2026-06-18現在）の公開連絡情報33件を分野・地域で検索できる形にした。領事館による推薦・斡旋ではなく、掲載先の受任、費用、対応地域、利益相反を保証しない。

同時に提供された個別の委任契約書は、安全な受付境界を確認する参考にとどめ、依頼者名、個別事件、報酬、支払条件、署名その他の非公開情報をコード、テスト、Git、画面へ収録していない。

Skyは相談本文をD1、実行履歴、Git、ログへ保存しない。法令AIを実行する場合だけ、利用者の同意後に相談本文をOpenAI APIへ送信する。Responses APIへは`store: false`を指定してAPIから後で取得するための応答保存を無効にするが、これはZero Data Retentionの保証ではなく、OpenAI側のデータ保持は契約・プロジェクト設定に従う。APIキーはサーバー側の`OPENAI_API_KEY`に置き、ブラウザへ渡さない。法令AIが未設定または失敗した場合も、決定的な緊急判定、公的窓口、弁護士引継ぎは動作する。

モデルは既定で`gpt-5.4-nano`を使い、必要ならサーバー側の`OPENAI_LEGAL_MODEL`で変更できる。利用者への表示料金は0円にできるが、OpenAI API利用料は運営側に発生する。弁護士への相談・依頼費用は別であり、受任前に直接確認する。

## 法的・安全上の境界

- 法的助言、期限計算、勝敗予測、事実認定を行わない。
- この受付だけでは弁護士・依頼者関係や秘匿特権は成立しない。
- 米国内で差し迫った危険がある場合は911、NYCのDV相談には24時間HOPE Hotlineを表示する。
- 自動連絡、受任保証、費用見積り、利益相反確認、本人確認、代理行為を行わない。
- 公的案内と候補の連絡先は変更される可能性があるため、利用時にリンク先と掲載先へ直接確認する。

## 検証

`tests/legal-intake.test.mjs`で、Skyのready商品登録、一般情報の非引継ぎ、危険時の911/HOPE表示、逮捕・7日以内期限の至急判定、刑事弁護だけの藤原茜弁護士優先、公的無料窓口、法令AIの非保存設定・公式ドメイン制限・引用必須、公開33件の一意性と連絡先、引継ぎ文が法的評価でないことを検査する。

ブラウザ検証では、Hubの「法律・生活支援」から受付を開き、一般情報では弁護士候補を出さずNY CourtHelp、LawHelpNY、U.S. Courtsを表示すること、進行中の刑事問題では藤原茜弁護士が第一連絡候補になることを確認した。法令AIのAPIキー未設定時も明確な案内を表示し、公的窓口と引継ぎは利用できる。エラーオーバーレイはなく、画面本文・入力・候補順も確認した。

2026-09-12のローカルSkyで、ready商品7件中の法務受付としてTimelineと役割ボタンに表示されること、1タップで幅980pxの会話画面が先頭から開くことを確認した。一般情報の非引継ぎ、雇用問題の引継ぎ要約と候補5件、危険・DV選択時の911／HOPE表示に加え、無料解決ルートと刑事弁護ルートを画面操作で確認した。`npm run verify`は124 tests、production build、仕事API 143 assertionsを含めて成功した。

## 未実装

弁護士側の受付可否・日程・費用のリアルタイム確認、相談履歴、相談予約、利益相反確認、法律事務所とのAPI連携、本人確認後の送信、米国外の緊急窓口は未実装。これらを現在の機能として表示しない。法令AIを本番で有効化するには、対象Sites環境へ`OPENAI_API_KEY`を秘密情報として設定する必要がある。
