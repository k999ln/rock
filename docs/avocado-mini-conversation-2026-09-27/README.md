# avocado Mini — 2026-09-27 会話仕様アーカイブ

このディレクトリは、2026-09-27までに依頼者が決めた avocado Mini の方向性と、その検討資料・生成画像を**原文のまま**保存するアーカイブである。追補資料に書かれた「提案」「未実装」「未検証」は確定仕様へ勝手に昇格させない。

## 決定した方向性

- Mini は Pro の単なる接続機器ではない。Mini 単体で基本操作、ローカル保存、対応アプリを動かす独立端末とする。
- Mini と Pro は RockstarOS の共通機能・共通APIを持つ。Pro はより大きな演算・保存容量などを担えるが、Miniの本人認証や基礎体験の前提にはしない。
- 利用開始は空間での個人登録から始める。顔はプロフィール候補の識別に使い、保護データの解錠は別の本人認証を通す。人が変われば、認証済みの本人の保存データへ切り替える。
- テレビやスマートフォンを必須の出力先にしない。スマートフォンは任意のリモコン・追加認証手段とする。裸眼空間表示は製品目標だが、現時点で成立・実装済みとは扱わない。
- 本体形状と背面下部の洋梨形ボタン、そこから伸びる蔦の意匠は固定扱いとする。前面へボタンを移さない。
- Mini対応ゲームのクリエイター収益分配は、**クリエイター80%、Mini運営20%**。分配対象額と適用対象はまだ事業・契約面の確定が必要である。
- GTA / Roblox は対応対象として検討する。ただし本体実行か外部実行か、ハードウェア変更、公式互換性、空間表示連携は未決・未検証である。Mini向けに作る新規ゲームは先に安全なSDK・配布・保存の経路を整える。
