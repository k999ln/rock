# avocadoMini R5 — 試作・資金計画

現行製品は[R5](avocado-mini-r5/README.md)。使用時200mm以内・銀色円筒1本・外部給電・別Hub不要を目指す独立空間端末である。旧Motion Tower/E1/E2/E3の構成、価格、配送時期をR5へ引き継がない。価格は未確定、募集・決済・先行予約は未開始。

試作で受け入れる順序は、収納・給電/熱・ローカル基本操作/停止 → 入力/保存/再起動/復旧 → 表示の研究gate → 任意の国内LTE/Pro/cloud接続。原本計算やBenchの成功をR5実機の完成にしない。[サービス実現順](service-design/04-delivery-and-acceptance.md)と[Mini担当](workstreams/11-material-invention-avocado-mini.md)の同一artifactで証拠を残す。

資金計画は製品の受入と分ける。ROCKが試作範囲、BOM/工数/外部実費、検証予算、達成/不成立条件をまとめ、EXTERNALとJOINTが供給・試作・募集サービスの現在の条件を確認する。OWNERが募集主体、地域、受取口座、見積、返礼、納期、返金/不成立条件を判断する。サービス選定・募集公開・契約・支出は、この文書の作成だけで実施したことにしない。

入口は`/avocado-mini`と`/rockstaros/crowdfunding`。現行R5・価格未確定・試作未受入を表示し、募集が始まる前に購入/支援可能と案内しない。一般のRockstarOSサービスは無料アカウントから開始し、Miniの購入を必要条件にしない。
