# Rock Wallet — 収益の共通精算口座

更新日: 2026-09-13

## 製品上の役割

Rock Walletは暗号資産専用Walletでも、手入力の家計簿でもない。Skyの自動化収益、ToB商品の販売収益、ファンドの共同収益を、入金証拠と実行記録に基づいて確認し、費用・返金・分配・払出しを管理するRockstarOSの共通精算口座とする。

資金の流れは、仕事または販売、外部Providerでの入金確認、精算と分配、Walletへの受取可能額確定、本人が選んだ払出し先への送金の順とする。暗号資産、銀行、ゲーム資産、ATMはWallet本体ではなく払出し・交換adapterとして分離する。

## 今回の実装

- Walletの最初の画面を「受取可能額」「Sky収益」「ファンド分配」「払出し」の状態確認へ変更した。
- 本人別D1台帳の手入力売上・経費は「未照合の記録」として補助タブへ分離し、受取可能額へ加算しない。
- 本人の保存済みファンド設定をWallet APIで読み、共同収益、分配原資、自分の分配額を試算として表示する。
- ファンド試算は実入金・受取可能額・投資持分として扱わない。
- 外部Providerが未接続の間、受取可能額を0円と断定せず「—」とし、実収益を保管・送金できる表示をしない。
- 手入力台帳は所有者分離、追記、取消、冪等性を維持する。

## 次の接続境界

実収益をWalletへ確定するには、BIL02の販売・決済・払出しProvider sandbox受入が必要。本人識別子を外部精算サービスへ渡す接続は、接続先、目的、保持、失効を確認し、明示承認を得るまで自動で有効化しない。

Provider接続後は、署名済みEarning Receiptから確定収益、保留、費用、返金、受取待ち、払出し済みを読み、ファンド分配ReceiptとSky収益Receiptを所有者・通貨・受取人別に表示する。
