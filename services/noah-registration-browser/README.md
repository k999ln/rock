# Noah owned registration browser

Noah owns this executor, workflow configuration, handoff UI, authentication and credential storage. Browser Use Cloud is a design reference, not a dependency. The existing Cloudflare account supplies isolated Chromium instances. No Browser Use account or model API key is required for these bounded registration workflows.

`npm ci --prefix services/noah-registration-browser`, then `npx wrangler deploy --config services/noah-registration-browser/wrangler.jsonc`. Its own SQLite Durable Objects contain only a claimed job, hashed owner, provider revision, browser session ID, expiry, input sequence and state. They never contain registration fields, cookies, screenshots or issued credentials. The existing Noah D1 schema is unchanged.

Install a random 32-byte `NOAH_BROWSER_KEY` using Wrangler secret bulk (stdin). Put the same value in Sites secret `NOAH_REGISTRATION_BROWSER_KEY`; set `NOAH_REGISTRATION_BROWSER_URL` to this worker's `/v1/session`. Preserve `NOAH_PROFILE_KEYS`. The public browser never gets these secrets or a CDP URL. Requests are HMAC-signed with a 30-second timestamp; replayed starts and input sequences do not execute again. Disable Worker observability; do not add request/body logging.

`NOAH_BROWSER_RECIPES` is an operator-managed JSON array, initially empty. Each recipe has `id`, integer `revision`, exact hostname `domains`, `startUrl`, `fields: [{key,selector,required}]`, `submit`, `credentialSelector`, `verifyUrl`, and `identityField`. Both URLs must be HTTPS on the fixed allowlist. The identity endpoint must accept Bearer authentication and return a non-empty top-level identity string. Registration fields must match the public Noah provider configuration. Bump both revisions when changing a workflow. A saved credential is bound to the entire Noah provider configuration, so a changed destination cannot receive an older credential.

Add the matching Noah provider with `execution: "browser"`, `requiresAccount: true`, `mcpUrl`, and this exact `executorUrl` only after a real provider acceptance test. This version supports fixed form fields and Bearer-authenticated MCP; it does not enable file upload, OAuth refresh flows, arbitrary tasks, JavaScript, shell commands, or arbitrary user URLs. A provider requiring those needs its own adapter. Official API registration uses the native executor instead.

One fresh browser per job; fixed 390 × 640 viewport; fixed network allowlist; no user's desktop or browser profile. Noah fills approved fields and submits once. The user handles verification through `/noah/registration/browser` (screen, tap, text, keyboard, scroll), then resumes. The runtime verifies the issued credential against the fixed identity endpoint. Noah encrypts it before closing the browser. A page's success text is insufficient. No screenshots or input text are stored; background UI polling stops and terminal jobs stop polling. Cancel/expiry closes the remote browser, but cannot undo an external registration already submitted.

Initial rollout reserves **ten browser minutes per UTC day (two four-minute sessions and one two-minute session)**, with a 21-second launch interval. This is an acceptance-test budget, not capacity for the planned 100-person rollout. It is deliberately not a paid-plan upgrade; account-wide usage by other workers may still exhaust the provider quota. Raise the budget only after confirming the account plan, provider behavior and operational cost. All response loss after dispatch is treated as uncertain, never as permission to register again.

The signed `fixture` workflow is internal only and is absent from the public provider registry. It fills a synthetic name in a self-contained page, pauses for a confirmation button, and returns `fixture: true` without credentials. It has an empty network allowlist and cannot register with an external service. It consumes the same production browser budget. It is not proof of a real external registration.

Verification: `node --experimental-strip-types --test tests/noah-browser-registration.test.mjs tests/noah-registration*.test.mjs`; `npm run verify`; `npx wrangler deploy --config services/noah-registration-browser/wrangler.jsonc --dry-run`. Record real browser acceptance separately from mocked HTTP tests.
