MADE TO BE EXTENDED

あなたの工夫を、ツールに。

文章レシピの作成から配布まで。Coreの再ビルドは不要です。

01   レシピを作成

利用できる処理：行の空白整理、空行整理、並べ替え、重複削除、行頭の追加、文字列の置換。

PYTHONPATH=src python3 -m blackberryrock.sdk new my-tool.json
PYTHONPATH=src python3 -m blackberryrock.sdk build-dev my-tool.json my-tool.rock.json
PYTHONPATH=src python3 -m blackberryrock.sdk check my-tool.rock.json
PYTHONPATH=src python3 -m blackberryrock.sdk publish-local my-tool.rock.json examples/registry

02   Skyで見つけて試す

「自動化を探す」の「一覧を更新」で、追加したパッケージを取得します。ダウンロード、権限の承認、実行、バージョン更新を同じ画面で検証できます。

開発専用：配布物は公開されたRFC 8032テスト鍵の署名を使用します。作者の本人性や本番配布の信頼性を保証する鍵ではありません。
