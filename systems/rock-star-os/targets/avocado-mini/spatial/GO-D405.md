# Go + D405 host observation preview

This is bounded source integration, **not accepted display/gesture hardware**. It has not been executed against Bridge or devices. No new tests or physical claims.

## Installed dependencies and private profiles

Use an owner-controlled Linux X11 host, its existing official Bridge Python SDK and exact pinned native library, plus pyrealsense2 2.56.5. This source does not install or download them. Exact CM5 GPU/OS/USB-C video compatibility is not accepted.

Copy the Go and D405 templates under `../linux/` to private storage outside Git. Supply received serials, exact Go device name, actual SDK version/library hash, common calibration ID/place epoch/expiry, and calibrated D405 sample pixels. EXTRINSIC supplies the same ID/epoch and rigid `cameraToPlace`. Do not invent calibration or post profiles/serials in source control. The Go reader checks scalar calibration only, not the full lenticular/subpixel data needed for rendering.

The official SDK constructor writes its telemetry preference. The explicit settings flag permits that behavior; this source requests tracking disabled. Enumerating Bridge does not stop an image already playing on Go. Independent optical stop remains unimplemented.

## Explicit local invocation

```sh
node --experimental-strip-types systems/rock-star-os/targets/avocado-mini/spatial/go-d405-preview-host.mjs \
  --allow-local-capture --allow-bridge-settings-update \
  GO_PRIVATE_PROFILE_JSON D405_PRIVATE_PROFILE_JSON EXTRINSIC_JSON
```

Fixed child sources, no shell, 12-second host bound. Go is observed first, then the D405 capture starts. Profiles are restricted to the current UID and cannot be group/world writable. The native library is hash pinned and cannot be group/world writable. No arbitrary program arguments, URLs, image files or remote services are accepted by this CLI.

## Receipts and limitations

- Go: exact serial/name/dimensions, stable scalar calibration hash, same-host received timestamp, boot and sequence. No GL window, texture submission or luminance command.
- D405: existing depth deprojection and rigid place transform; no hand inference, bounded positional error or mapped exposure timestamp.
- Session: calibration/place identity matched, Go receipt age ≤500 ms and depth retrieval age ≤100 ms; disconnect/changed/replayed/stale data revokes it. Timing is freshness of retrieval, not synchronization of exposure with scanout.
- Combined receipt: `not-submitted`, action eligible false, physical accepted false. It must not enter the existing synthetic-action path as an accepted real tap.
- Source/provider/hardware costs, account, workflow and all billing state are unchanged.

To progress to displayed content, implement and accept exact Go rendering/subpixel calibration, measured optical warp and pupil coverage, mode-specific comfort measurements, scanout readback, a hardware stop including Go's autonomous playback and USB power paths, and sensor exposure/error/gesture qualification. The current two-lens candidate study does not satisfy few-node room-wide visibility.
