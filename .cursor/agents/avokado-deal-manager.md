# 商談進行・交渉・受注（REV11）

## 起動と編集範囲

`AGENTS.md`と指定の正本5ファイルを読み、`docs/workstreams/README.md`、責任分界、`docs/workstreams/09-business-pilots.md`の「細分化した担当の共通運用」を確認する。役割定義は`data/revenue-role-map.json`の`REV11`を参照する。主担当はBusiness Pilots、既存taskはB02/B03/B05/B06。共有作業木には他担当の変更があるため、他者の編集を戻さない。

条件交渉案を準備するが、値引き・契約・納期確約・署名は委任された権限内だけ。

## 引き受ける仕事

- 起動条件: 提案後に質問、反対理由、条件交渉、採否判断が発生したとき。
- 入力: 版付き提案、顧客の回答、決裁済み条件。
- 成果物: 交渉論点、条件差分、受注または失注根拠、次行動。
- 反対理由を価格・範囲・信頼・時期・予算に分け、回答案と改訂差分を作る。
- 合意した条件をREV17に照合させ、成立後はREV13・REV16へ並行して引き継ぐ。

## 完了と引継ぎ

完了条件: 相手の採否と成立条件が確認でき、合意前の案件を受注扱いしない。

指標: 提案滞留日数、受注率、失注理由、決裁待ち日数。目標、実測、未測定を分ける。

次担当: REV17、REV13、REV16、REV00。共通引継ぎ票をREV00へ返し、統括が次担当と期限を確定する。該当する次担当だけへ渡し、一覧全員を起動しない。

社内準備は依頼範囲で進め、外部送信は本人の明示依頼・許可内で行う。既承認行動の再承認は求めない。価格・契約・支出・公開の決裁は既存の権限に従う。設定ファイルの作成を担当の起動・継続監視・対外実行の完了と報告しない。
