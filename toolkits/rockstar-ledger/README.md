# サブスク顧問 — Sky接続

Skyの自動化Hubから、PC内で動くRockstar Ledgerのサブスク台帳を読み取り専用で確認する接続です。

## 導入

1. Skyの「PC・MCP接続」で最新版の接続アプリを起動し、このPCを接続します。
2. Skyの「サブスク顧問」で「OSに導入して起動」を押します。
3. OSが配布ZIPとプラグイン定義のSHA-256、権限、保存先、MCP機能を確認し、`http://127.0.0.1:8765` で起動します。

手動導入も残しています。Skyの商品画面からZIPを取得して展開し、`python3 scripts/run_local.py` を実行します。

Skyには月額換算、契約・候補数、要対応、更新日と警告が表示されます。「全網羅されてる？」「今月いくら？」「要対応は？」「次の更新は？」などをサブスク顧問へ会話形式で質問できます。回答は表示時に取得したローカル台帳だけから作り、外部AIへ送りません。契約や明細の実データはRockstar Ledgerの `data/ledger.sqlite3` にだけ保存され、Gitには含まれません。

Rockstar Ledger 0.2の「全網羅チェック」は、Apple、Google Play、クレジットカード、銀行口座、PayPal、請求メール・領収書ごとに、利用有無、取込、確認済み、確認期間を記録します。未確認の情報源または継続契約の更新日不足が残る間は、Skyも台帳も「全網羅」と判定しません。過去の契約は終了・解約済みとして残し、CSVを取り込むと情報源と対象期間も更新します。

CodexなどからMCPで使う場合は、展開先の `.mcp.json` を読み込むか `python3 scripts/mcp_server.py` をstdioサーバーとして登録します。

## 境界

- Sky側は確認専用です。追加・編集・解約・支払い・税務申告は実行しません。
- 異なる通貨を勝手に換算・合算しません。
- 「確認済み」は契約先や明細の履歴を実際に照合した情報源だけに設定します。候補の存在やCSV取込だけで全網羅とは表示しません。
- 現在のワンタップ導入と直接接続はローカル開発版Skyと同じPCでの利用が対象です。HTTPSで配信されたWeb版からHTTPのloopbackへ接続する構成は対象外です。
- OS管理層は審査済みカタログに固定されたパッケージだけを扱い、任意URL、任意コマンド、任意保存先は受け取りません。アプリ本体を削除しても、台帳データと操作receiptは保持します。
- Native OS rootfsへの組込みとPlatform IPCは実装済みです。今回の確認はホスト上であり、QEMU/実機ブートとWalletへの費用転記は未確認です。
