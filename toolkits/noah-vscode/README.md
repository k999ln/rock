# Noah 保存時リファクタ

VS Codeで保存した対象コードを、Noahで接続した公式Aiderへ渡します。元コードと修正候補に同じ固定テストを実行し、検証に通り、編集中の版と一致した場合だけ保存します。

## 使う

1. このMacでNoahを起動し、Aiderの詳細から「接続する」を押します。
2. VS Codeの「Extensions: Install from VSIX...」で `noah-save-refactor-0.1.0.vsix` を導入します。
3. 信頼済みのワークスペースで対象コードを保存して開き、コマンドパレットから「Noah: このファイルを保存時リファクタに接続」を実行します。
4. 対応する `.test.mjs` を選び、開いたNoahの保存時運用画面で「運用開始」を押します。
5. 対象ファイルを編集して保存します。修正と検証は非同期です。結果は「出力」→「Noah 保存時リファクタ」で確認できます。

Noah画面または「Noah: 保存時リファクタを停止」で止められます。「Noah: 直前のリファクタ前へ復元」は運用を止め、最後に自動保存した版から元へ戻します。その後に本人が編集したファイルは上書きしません。

## 対応範囲

- 最初の版は、1ワークスペースにつき外部依存なしの小さいJS/TSコード1ファイルとNodeテスト1ファイル。JSは構文と指定テスト、TSは追加でstrict型検査を行います。TSのNode型定義や外部パッケージは取り込みません。
- 合計プロンプト12KB、各ファイル16KB以内。外部ファイルをimportするコードやプロジェクト全体のリファクタは未対応です。
- 対象コードは保存済みで画面に開いておく必要があります。編集中・テスト失敗・停止・接続切れでは修正を適用しません。Agent自身の保存から新しい仕事は起こしません。
- このMacの `http://127.0.0.1:3107` のNoah、VS Code、既存ローカルモデル、隔離実行環境が必要です。Macを閉じた間は動きません。
- Noah再起動後は接続コマンドをやり直して、運用を再開します。Gitのcommit/pushや外部有料APIは使いません。
- 変更前のコードはVS Codeのワークスペース用拡張ストレージにWork別で保存します（最大100件）。復元データの削除・自動ローテーションは行いません。
- 指定テストの成功は、未試験の挙動やプログラム全体の正しさを保証しません。実行結果はNoahのAider詳細から確認できます。

## ローカルパッケージ

このフォルダで `npx @vscode/vsce@4.1.1 package --no-dependencies --allow-missing-repository --out noah-save-refactor-0.1.0.vsix` を実行します。Marketplaceへの公開操作は含みません。
